# BankaBot

Choose the part of BankaBot you need for a Lineage 2 task: preparing a supported client, defining behavior, displaying objects, working with geodata, or writing a script.

These guides describe the BankaBot edition documented in March 2026. Its game-specific data and commands require the matching BankaBot distribution and its supported environment. Installing ordinary EyeAuras does not by itself provide those objects or commands.

## Choose your starting point

1. Start with [Getting started](/en/BankaBot/getting-started) to identify your distribution, client, server and access requirements.
2. Choose one small goal from the table. For example, reduce clutter in an object display before trying to automate a route.
3. Read that guide with your edition's instructions available. Check where it obtains the required state or data before configuring a reaction.

| Your goal | Read next |
| --- | --- |
| Prepare a particular BankaBot edition and game window | [Getting started](/en/BankaBot/getting-started) |
| Choose a target and organize checks before an action | [Behavior trees](/en/BankaBot/behavior-trees) |
| Show, hide or highlight players and other objects | [Rules](/en/BankaBot/rules) |
| Understand obstacles and prepare navigation data | [Geodata](/en/BankaBot/geodata) |
| Combine events, timers and custom logic in C# | [Scripting](/en/BankaBot/scripting/getting-started) |
| Decide which subject answers a particular question | [Documentation topics](/en/BankaBot/documentation-topics) |

A display rule can change an object's appearance; it does not select a combat target. Geodata can describe an obstacle; it does not supply a character's HP or decide when to use a skill. Keep the data source, decision and reaction separate as you build a scenario.

For general EyeAuras features, start at [EyeAuras documentation](/en/home). BankaBot-specific requirements still come from the matching edition.
