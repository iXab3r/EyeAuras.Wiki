# Отправить одну случайную клавишу в свой редактор

Выберем одну клавишу из `1`, `2`, `4`, `5`, `A`, `D` и отправим одно нажатие в собственное пробное текстовое окно. Это не последовательный перебор: при каждом запуске заново выбирается случайный элемент, поэтому повторы допустимы.

Нужен настольный EyeAuras с **Windows Input** и выбором окна OSD. Откройте пустое текстовое поле своего редактора, поставьте в него каретку, выберите английскую раскладку и отпустите модификаторы. Не используйте чат или форму отправки.

1. Добавьте **C# Script** в свою тестовую ауру. Для первого опыта запускайте его вручную через **Run**.
2. Вставьте весь код в `Script.csx`:

```csharp
using EyeAuras.Roxy.Api;
using EyeAuras.Shared.Osd;
using System.Windows.Input;

{
    var target = await GetService<IOsdSelectionService>().PickWindow();
    if (target == null || !target.IsWindow) { Log.Warn("Окно не выбрано"); return; }
    var keys = new[] { Key.D1, Key.D2, Key.D4, Key.D5, Key.A, Key.D };
    var key = keys[System.Random.Shared.Next(keys.Length)];
    var input = GetService<ISendInputScriptingApi>();
    var previousSimulator = input.InputSimulatorId;
    var previousTarget = input.TargetWindow;
    try
    {
        input.InputSimulatorId = "Windows Input";
        input.TargetWindow = target;
        cancellationToken.ThrowIfCancellationRequested();
        Log.Info($"Окно: {target.Title}; клавиша: {key}");
        input.KeyPress(key, 20);
    }
    finally
    {
        input.TargetWindow = previousTarget;
        input.InputSimulatorId = previousSimulator;
    }
}
```

3. Нажмите **Run**, укажите своё подготовленное окно. Стандартный ввод активирует адресата; символ появится в поле с кареткой. Escape или правая кнопка отменяет выбор окна.
4. Повторите Run несколько раз: в журнале видна выбранная клавиша, в редакторе — результат её доставки. Один и тот же символ может повториться.

| Настройка | Значение в примере |
| --- | --- |
| `keys` | Шесть разных клавиш; каждая выбирается с вероятностью 1/6. Если добавить дубликат в массив, он увеличит вероятность соответствующей клавиши. |
| Число повторов | Одно нажатие за запуск; автоматического цикла и межоперационного интервала здесь нет. |
| `20` в `KeyPress` | Задержка между нажатием и отпусканием в миллисекундах, не период повторов. Без аргумента используется `KeyPressDelay` API. |
| `TargetWindow` | Явно выбранное собственное окно. Это адресный ввод с активацией, не универсальный фоновый ввод. |

Клавиши отличаются от готового текста: результат зависит от раскладки, модификаторов и фокуса внутри окна. Токен проверяется перед вводом; синхронный `KeyPress` не получает токен запуска и уже начатое действие им не прерывается. Прежние настройки заимствованного API восстанавливаются в `finally`.

<details>
<summary>Запуск горячей клавишей и прежний активный адресат</summary>

Можно добавить **Hotkey Is Active → Hold** с `F3` и действие в **On Enter**. Каждая новая активация выберет одну клавишу; отпускание позволяет активировать ауру снова. Выбор собственного окна остаётся частью каждого запуска.

В старом варианте использовался `input.TargetWindow = null`: у Windows Input это текущее активное приложение. Это не отсутствие ввода и не автоматический выбор безопасного редактора. Явный выбор выше делает адресата понятным до нажатия. Другие способы доставки — по [контракту SendInput](/ru/scripting/api/ISendInputScriptingApi). Обычному C# классу передавайте сервис явно, а не рассчитывайте на глобальный `GetService`.

</details>
