# Вывести сообщение и повторить его по F1

Этот минимальный скрипт записывает одну строку в журнал EyeAuras. Входных данных и внешних пакетов нет: сообщение берётся из кода, а `Log` предоставляет работающий хост `C# Script`.

Можно [импортировать готовый пример](https://eu.eyeauras.net/share/S20240223231508UC4AdkJYNJjI) или создать его вручную в собственной ауре.

1. Создайте ауру и добавьте `C# Script` в `On Enter`.

2. Вставьте в верхнеуровневый `Script.csx` всю программу:

```csharp
Log.Info("Hello, world!");
```

3. Нажмите `Run` в редакторе.

4. В `Event Log` этого действия найдите строку `Hello, world!`. Повторный `Run` добавит ещё одну строку. Код завершается сразу после записи; останавливать его вручную не требуется.

Иллюстрации настройки клавиши ниже показывают прежнее оформление редактора. Проверяемый результат — текст в журнале выбранного действия. В обычном C#-классе `Log` нужно получить через переданную зависимость; копирование этой строки в произвольный проект не создаёт логгер.

Чтобы следующим шагом поработать с меняющимися данными, возьмите [пример типизированного счётчика](/ru/scripting/examples/basic/variables). Он хранит значение у своего владельца: повторные запуски увеличивают число, а не выводят одну постоянную строку.

## Запускать действие клавишей

1. В той же ауре добавьте триггер `Hotkey Is Active`.

![](https://i.imgur.com/j7ma0e1.png)

2. Укажите `F1` и выберите `Hold`. Оставьте скрипт в `On Enter`.

![](https://i.imgur.com/s3eKrnp.png)

3. Нажмите и отпустите `F1`: аура войдёт в активное состояние и выполнит действие. Повторите нажатие с отпусканием — появится ещё одна строка.

| Режим | Что происходит с состоянием |
| --- | --- |
| `Hold` | Активно от KeyDown до KeyUp. Два отдельных нажатия с отпусканием дают два входа в активное состояние. |
| `Toggle` | Переключается на KeyUp. Первый цикл нажатия включает состояние, второй выключает; второе нажатие не выполняет `On Enter` ещё раз. В коде трекера этот режим называется `Click`. |

Это переходы состояния, а не очередь для бесконечного числа долгих запусков. Пример короткий и завершается до следующего нажатия. Детали переходов видны в [HotkeyTracker](https://github.com/iXab3r/PoeEye/blob/0e02c98dcab4bff263684f1c0647eed120e2700f/PoeEye/PoeShared.Wpf/UI/Hotkeys/HotkeyTracker.cs).
