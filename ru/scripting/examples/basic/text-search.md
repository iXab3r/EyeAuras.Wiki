# Прочитать строку из собственного окна

Покажите в своём текстовом редакторе строку `Build ready` крупным тёмным шрифтом на светлом фоне. `Text Search` распознает её с изображения окна, а скрипт выведет полученный текст в журнал. Это OCR — чтение видимых пикселей, а не обращение к документу или внутренним данным приложения.

Нужны доступный захват/OpenCV и установленный OCR-движок для английского текста. Сначала проверьте, что нужный вариант есть в `OCR Symbols`; имя движка в статье не устанавливает языковые файлы. Можно [импортировать исходный пример](https://eu.eyeauras.net/share/S20240223231042V9jd1AoFcJ6v).

1. Создайте в одной папке ауру `TextSearch` с триггером `Text Search` и соседнюю ауру `Script` с действием `C# Script`.
2. В триггере выберите собственное окно и небольшую область вокруг строки. Для первого опыта не добавляйте эффекты.
3. Настройте OCR и нажмите `Refresh Once`. В поле `Recognized text` должна появиться ваша строка; если её нет, сначала исправьте захват, язык или читаемость изображения.

| Настройка | Для этого примера |
| --- | --- |
| `OCR Symbols` | `Tesseract (eng)`, если он установлен и есть в списке, либо доступный английский OCR вашей установки. |
| `Scale factor` | 1 для крупного читаемого текста. Увеличение помогает мелкому тексту, но меняет изображение, которое получает OCR. |
| `Invert image`, `Binary threshold` | Сначала выключены. При необходимости проверяйте каждое изменение по распознанному тексту. |
| `Include text segments` | Для вывода всей строки не требуется. Для рамок отдельных сегментов понадобится в [примере клика](/ru/scripting/examples/basic/click-on-text). |

4. В `Script.csx` соседнего действия вставьте полный код и нажмите `Run`:

```csharp
using EyeAuras.OpenCVAuras.Triggers.TextSearch;
using System.Linq;

var trigger = AuraTree.GetAuraByPath(@".\TextSearch") // находим ауру по имени
    .Triggers.Items // перебираем все триггеры
    .OfType<ITextSearchTrigger>() // и находим триггеры "Поиск текста"
    .First(); // из всех берем первый, если не найдено - будет ошибка

var matchResult = await trigger.RefreshAsync(cancellationToken); // новый захват и OCR
var text = matchResult.Detected.Text;
if (string.IsNullOrWhiteSpace(text))
{
    Log.Warn("Text was not recognized; check capture and OCR settings");
    return;
}
Log.Info($"Text: {text}");
```

В `Event Log` появится `Text: Build ready` — возможны пробелы и переводы строк, добавленные OCR. Предупреждение означает, что непустой текст не получен; проверьте диагностику, потому что пустая строка не доказывает отсутствие надписи.

`Detected.Text` — результат распознавания. `Detected.Success` дополнительно зависит от [условия проверки текста](/ru/features/text-match-expressions) в триггере: строка может быть распознана, даже если условие не совпало. Этот пример намеренно выводит текст, а не запускает реакцию по состоянию ауры.

Код выполняется в верхнеуровневом `C# Script` работающего EyeAuras. `AuraTree`, `Log` и `cancellationToken` предоставляет хост; обычный класс получает службы явно. `GetAuraByPath` и `First()` требуют подготовленную ауру и триггер.

`RefreshAsync(cancellationToken)` передаёт токен в получение кадра и обработку запроса; нативное OCR может завершаться не сразу после Stop. Есть и блокирующий `Refresh(cancellationToken)`. Триггер из дерева не нужно освобождать, а данные этого обновления приходят без буферов изображений. Полная настройка — в [Text Search](/ru/triggers/images/text-search), контракты — в [карте CV](/ru/scripting/api/computer-vision/images).
