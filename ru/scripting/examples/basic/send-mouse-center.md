# Один раз переместить курсор в центр основного экрана

По нажатию `F3` скрипт вычислит середину основного монитора и переместит туда настоящий курсор. Он не нажимает кнопки мыши. Здесь источник координат — размер основного экрана Windows, а не найденная аура, окно или его клиентская область.

Нужен настольный EyeAuras с доступным `Windows Input`. Подготовьте собственную тестовую рабочую область без перетаскивания объектов. Можно [импортировать исходный пример](https://eu.eyeauras.net/share/S202402240046520BBKcR6QKL07) или собрать его вручную:

1. Создайте ауру и добавьте [Hotkey Is Active](/ru/triggers/hotkey-is-active).
2. Задайте `F3`, режим `Hold`. Добавьте действие `C# Script` в `On Enter`.
3. Вставьте весь код в `Script.csx`:

```csharp
using EyeAuras.Roxy.Api;
using PoeShared.Scaffolding;

var sendInputApi = GetService<ISendInputScriptingApi>(); // нужно для отправки ввода
sendInputApi.InputSimulatorId = "Windows Input";
sendInputApi.TargetWindow = null; // экранная точка, без преобразования относительно окна
var screenSize = System.Windows.Forms.SystemInformation.PrimaryMonitorSize; // берем размер основного экрана
Log.Info($"Primary monitor size: {screenSize}");

cancellationToken.ThrowIfCancellationRequested();
sendInputApi.MouseMoveTo(screenSize.Width / 2, screenSize.Height / 2); // переводим в центр
```

4. Нажмите и отпустите `F3`. В журнале появится размер основного монитора, а курсор окажется в его центре. Следующее отдельное нажатие повторит одно перемещение.

| Выбор | Значение для примера |
| --- | --- |
| `InputSimulatorId` | `Windows Input`. Недоступный механизм даст ошибку, а не подтверждение движения. |
| `TargetWindow` | `null`: точка уже экранная, дополнительная привязка к окну не нужна. |
| `PrimaryMonitorSize` | Размер только основного монитора. Его середина не равна середине всего виртуального рабочего стола. |
| `MouseMoveTo` | Абсолютное положение. `MouseMoveBy` означал бы смещение от текущего положения. |

Основной монитор имеет экранное начало `(0, 0)`; пример делит его ширину и высоту пополам. Не подставляйте сюда размер окна, оставив тот же смысл координат: при ненулевом `TargetWindow` стандартный контроллер активирует окно и добавляет начало его `DwmFrameBounds`, а это не начало клиентской области.

Проверка токена выполняется перед движением. Сам синхронный вызов не принимает токен Run и не возвращает подтверждение от приложения; если движение заблокировано, изучите диагностику. Сервис заимствован из контекста скрипта, отдельно освобождать его не нужно. `GetService`, `Log` и `cancellationToken` доступны именно в верхнеуровневом хосте EyeAuras.

В `Toggle` второе нажатие выключило бы ауру и не дало нового `On Enter`; для этого короткого примера выбран `Hold`. Контракты выбора координат и механизма — в [карте ввода](/ru/scripting/api/windows-subsystems/input-hooks-hotkeys).
