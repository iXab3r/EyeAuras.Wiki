# Выбрать следующий пример скрипта

Если первый скрипт уже запускается, выберите одну следующую задачу: сохранить значение, найти ауру, показать окно или обработать изображение. Ниже собраны существующие материалы. Для повторения примера нужны его файлы, зависимости и подходящий хост; название темы не означает, что любой её вариант доступен в каждой сборке.

1. Если ещё не запускали код, начните с [первого Run](/ru/scripting/getting-started), затем откройте полный [Hello, World!](/ru/scripting/examples/basic/hello-world).
2. Выберите задачу из таблицы. Откройте пример целиком: проверьте, куда помещаются `Script.csx`, обычные `.cs`-файлы и ресурсы.
3. Сравните ожидаемый результат с нужным вам. Для первого опыта оставьте собственное тестовое окно и одно действие; расширяйте пример после понятного результата.
4. Когда нужно уточнить имя метода или тип, используйте [карты API](/ru/scripting/api/core/eyeauras-structure) для поиска нужной области, а контракт проверяйте по справочнику своей версии и зависимостям проекта.

| Задача | С чего начать |
|---|---|
| Разобраться в C# и окружении скрипта | [Контекст скрипта](/ru/scripting/sandbox): верхнеуровневый код, доступные возможности и отличия от обычного класса. |
| Сохранить значение между запусками | [Пример переменных](/ru/scripting/examples/basic/variables): локальное значение, состояние запуска и переменные владельца имеют разный срок жизни. |
| Найти ауру и прочитать её данные | [Find Aura](/ru/scripting/examples/basic/find-aura), затем контракты [IAuraAccessor](/ru/scripting/api/IAuraAccessor) и [AuraTree](/ru/scripting/api/IAuraTreeScriptingApi). |
| Получить нужную службу | [Зависимости и контекст](/ru/scripting/api/scripting/runtime): `GetService<T>()` разрешает зарегистрированную службу; её наличие зависит от хоста и модулей. |
| Переместить мышь или ввести текст | [Центр выбранного окна](/ru/scripting/examples/basic/send-mouse-center) и [отправка текста](/ru/scripting/examples/basic/send-text): адресат и способ ввода задаются явно. |
| Нарисовать отметку или собственный интерфейс | [Метка у курсора](/ru/scripting/examples/basic/osd-cursor), [наблюдение мыши с оверлеем](/ru/scripting/examples/basic/mouse-track-with-overlay), [Blazor-окно](/ru/scripting/blazor-windows/getting-started). Это разные способы отображения. |
| Найти изображение перед действием | [Image Search в скрипте](/ru/scripting/examples/basic/image-search). Условие клавиши можно изучить отдельно через [Hotkey Is Active](/ru/triggers/hotkey-is-active); соединение условий требует собственной настройки. |
| Дождаться работы и корректно остановиться | [Асинхронные операции](/ru/scripting/api/scripting/async): ожидаемая задача, токен отмены и освобождение ресурсов. `async` само по себе не переносит любую операцию в другой поток. |

Результат выбора — конкретный пример с понятным входом и наблюдаемым выходом. Глобальные возможности `Log`, `AuraTree`, `Variables`, `GetService` и `cancellationToken` относятся к верхнеуровневому хосту скрипта. Обычный C#-класс или Razor-компонент получает зависимости отдельно; перенос текста из `Script.csx` без этого может изменить смысл программы.
