# Выбрать окно для своей панели

Панели настроек обычно нужен заголовок и возможность перемещения. Индикатору поверх другого окна удобнее обойтись без рамки. В **C# Overlay** это два режима одного оконного механизма: содержимое компонента остаётся тем же.

[WebView2](https://developer.microsoft.com/en-us/microsoft-edge/webview2) отображает HTML/CSS внутри нативного окна. Blazor связывает этот интерфейс с C#, а Blazor Windows соединяет компонент с оконным механизмом EyeAuras.

![WebView2 внутри окна EyeAuras](https://s3.eyeauras.net/media/2025/05/WebView2.drawio%20(1).png)

## Сравнить Window и Overlay

Для опыта нужен собственный **C# Overlay** со стандартным счётчиком и активная аура: например, с **Fixed Value → Is Active**. В списке оверлеев выбирайте текущий **C# Overlay**; старые снимки показывают его как v3.

![Виды оверлеев в прежнем меню](https://s3.eyeauras.net/media/2025/05/mIYLrG2yj2.png)

1. Откройте настройки добавленного C# Overlay. В **Window Settings** выберите **Window**, задайте заголовок `Моя панель`.
2. В **Position** задайте ширину `400` и высоту `200`. Снимите **Is Locked**, чтобы изменять положение и размер окна.
3. В **Visual style** выключите **Click-Through mode**, чтобы кнопка принимала нажатия. Оставьте **Opacity** равным `100%`.
4. Нажмите **Click Me**: счётчик увеличится. Затем переключите **Window Settings → Overlay**. Заголовок и системная рамка исчезнут, содержимое счётчика сохранится.

![Режим Window с заголовком](https://s3.eyeauras.net/media/2025/05/Njy7t9XEg2.png)
![То же содержимое в режиме Overlay](https://s3.eyeauras.net/media/2025/05/R432QeysKh.png)

| Настройка | Как выбрать |
| --- | --- |
| `Window` | Панель с заголовком и системным оформлением. В этом C# Overlay кнопка закрытия отключена: видимостью управляет аура. |
| `Overlay` | Панель без заголовка и системных кнопок. Этот режим принудительно показывает окно поверх остальных. |
| `Always On Top` | Управляет положением поверх других окон в режиме Window. Для Overlay это поведение уже включено. |
| `Is Locked` | Запрещает изменение размера и обычное перемещение; это не выключатель кнопок внутри компонента. |
| `Moveable even if Locked` | Отдельная возможность перемещения закреплённого окна. |
| `Click-Through mode` | Пропускает ввод сквозь окно при выполнении условий этого режима. Для интерактивной панели оставьте выключенным. В C# Overlay он применяется к закреплённому окну, когда главное окно EyeAuras не активно. |
| `Opacity`, фон и рамка | Меняют оформление окна. Прозрачность сама по себе не означает пропускание ввода. |
| Условия активности ауры | Определяют показ оверлея. При скрытии окно и компонент могут остаться живыми. |

Если окно не появилось, сначала проверьте активность и загрузку ауры, затем ошибки компиляции. Если окно видно, но кнопка не нажимается, проверьте **Click-Through mode**.

## Компонент и окно — разные части

Редактор C# Overlay компилирует проект и выбирает открытый тип компонента для отображения. `UserOverlay.razor` описывает содержимое, а перечисленные выше настройки — его окно. `Script.csx` выполняется как точка входа; он должен завершить подготовку, чтобы оверлей мог отобразиться. Бесконечное ожидание в этой точке входа остановит показ.

Компонент получает сервисы через `[Inject]`. Переменные `Script.csx`, его `GetService` и `cancellationToken` не становятся глобальными именами Razor. [Следующая статья](/ru/scripting/blazor-windows/3-hello-world) показывает согласованные файлы компонента, а [отдельный пример](/ru/scripting/blazor-windows/getting-started) создаёт окно через действие C# Script.
