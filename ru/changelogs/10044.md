# Alpha - 1.9.10044 [RU](/ru/changelogs/10044)/[EN](/en/changelogs/10044)

Патч с исправлениями Behavior Tree, EyePad и обмена макросами.

При запуске иногда возможна долгая загрузка. Причину ещё разбираю.

## Исправления / улучшения

* **[Behavior Tree]** Timeout и Interrupter теперь прерывают ожидающее действие, если оно поддерживает отмену, и дожидаются его завершения.
* **[Behavior Tree]** Поправил повторный запуск после выгрузки дерева и переключение общего SubTree между вызывающими деревьями. Старое выполнение завершается перед новым.
* **[Макросы]** Исправил поиск связанных макросов и деревьев при экспорте и имя файла при сохранении набора без аур. Название связанного макроса теперь обновляется после переименования.
* **[EyePad]** Исправил синхронизацию текста при быстром вводе и защиту вкладок только для чтения при открытии. Применение автодополнения доступно в редактируемых вкладках.
* **[EyePad]** Поправил восстановление открытых файлов при запуске и контекстное меню вкладок.
* **[Скрипты]** Исправил импорт C#-решений с пробелами в именах и путях проектов. Добавил распознавание проектов SDK-формата.
* **[Окна]** Привязал диалоги открытия и сохранения файлов к вызвавшему их окну. Исправил пустую страницу при Reload до завершения первоначальной загрузки.
* **[Экспорт]** После экспорта набора или C#-проекта Проводник открывается по кнопке Open in Explorer, а не автоматически.
* **[AI Assistant]** По умолчанию EyeAuras использует свою версию Codex и скачивает её при необходимости. Установки Codex из редакторов и npm больше не подхватываются автоматически.
