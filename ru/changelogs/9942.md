# Большая альфа - 1.9.9942 [RU](/ru/changelogs/9942)/[EN](/en/changelogs/9942)

Вот и пришел тот момент, о котором я писал еще в [1.9.9339](/ru/changelogs/9339) - старую WPF-оболочку отключаем.

Последние несколько месяцев WPF и Blazor интерфейсы жили параллельно. Blazor UI уже давно был доступен и для большинства пользователей включался по умолчанию. Теперь переключателя между оболочками больше нет - старую убираем окончательно, все дальнейшие изменения будут идти только в Blazor UI.

Внутри это очень большой апдейт, поэтому сначала выпускаю его только в **Alpha**. Баги наверняка будут :) Stable пока остается на `1.9.9774`.

## Оверлеи

Оверлеи были одним из последних больших кусков старого интерфейса. В этой сборке их редакторы и основная логика окончательно переехали в Blazor UI.

Больше всего изменений получил `Replica Overlay`: переделан выбор региона, ресайз и сам редактор. Во время выбора региона Replica теперь затемняется, а с зажатым `Shift` можно менять размер с сохранением пропорций.

Отдельный `Web UI Overlay` объединен с `C# Overlay`. Старые конфиги должны переехать автоматически.

## Исправления / улучшения

* **[Target Window]** Исправлен неприятный баг, из-за которого введенное значение вроде `PathOfExile.exe#2` могло само заменяться строкой с адресом окна, процессом и заголовком.
* **[Bindings]** Вернул Binding для `Target Window` в `ML Search`, `Image Search`, `Color Search`, `Text Search` и другие триггеры, действия и оверлеи, которые работают с окном.
* **[UI]** Доработаны выбор региона и изменение размера оверлеев.
* **[UI]** Доработано отображение ошибок и диагностической информации.
