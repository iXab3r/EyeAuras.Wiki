# Alpha - 1.9.10036 [RU](/ru/changelogs/10036)/[EN](/en/changelogs/10036)

Небольшой патч с исправлениями макросов, EyePad и интерфейса.

## Исправления / улучшения

* **[Авторизация]** Доработал загрузку авторизации при запуске.
* **[Макросы]** Исправил выбор ветки в IfThenElse и выход из Repeat через Break. Также поправил загрузку профилей, содержащих только макросы.
* **[Behavior Tree]** Исправил потерю фокуса при переименовании деревьев и макросов, а также отображение места вставки при перетаскивании узлов.
* **[EyePad]** Поправил переименование файлов и позиции подсказок в редакторе кода.
* **[Скрипты]** Исправил выбор основного скриптового проекта при загрузке решения с несколькими проектами.
* **[Окна]** Исправил случаи, когда окно продолжало перемещаться после отпускания кнопки мыши.
