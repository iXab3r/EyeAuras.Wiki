# BankaBot — выбрать нужную часть руководства

Если у вас есть отдельная поставка BankaBot для Lineage 2, начните с подготовки, затем выбирайте настройку поведения, отображения или навигации. Этот раздел сохраняет описание той поставки. Установка обычного EyeAuras сама по себе не добавляет BankaBot, игровые объекты или его геодату.

## С чего начать именно вам

1. Сначала откройте [подготовку BankaBot](/ru/BankaBot/getting-started): сопоставьте имеющуюся поставку, доступ к ней и поддерживаемое окружение. Название EyeAuras на окне ещё не определяет набор подключённых возможностей.
2. Выберите одну задачу из таблицы. Не смешивайте настройку показа целей с командами управления персонажем.
3. Прочитайте требования выбранной страницы до изменения своей конфигурации. Для игровых условий нужны данные среды BankaBot, для навигации — отдельный совместимый набор мира.

| Ваша задача | Куда перейти |
| --- | --- |
| Понять состав поставки и порядок подготовки | [С чего начать](/ru/BankaBot/getting-started) |
| Разделить выбор цели, действие и приоритеты | [Деревья поведения](/ru/BankaBot/behavior-trees) |
| Подсвечивать одни объекты и скрывать другие | [Правила и OSD](/ru/BankaBot/rules) |
| Разобраться с данными проходимости | [Геодата](/ru/BankaBot/geodata) |
| Организовать свою логику и её зависимости | [Скрипты](/ru/BankaBot/scripting/getting-started) |
| Найти тему по конкретному вопросу | [Навигация по разделу](/ru/BankaBot/documentation-topics) |

Например, если объект уже отображается, но его метка мешает на экране, начинайте с правил. Если вопрос в обходе стены, сначала разберите геодату. Ни цвет метки, ни файл геодаты не заменяют проверку подходящей цели в логике поведения.

Это историческое руководство по специальному компоненту, а не обещание текущей совместимости с любым сервером. Для конкретной поставки важны её версия, сопровождающая документация и сведения её издателя. Возможности обычного EyeAuras отдельно описаны в [общем руководстве](/ru/home).
