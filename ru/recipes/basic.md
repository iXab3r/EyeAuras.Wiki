# Получить полезный результат без кода

Эти задачи используют обычные редакторы аур, триггеров, действий и оверлеев. Каждый рецепт содержит собственные требования и настройку: проходить остальные рецепты заранее не нужно. Для опыта достаточно небольшого набора, своих окон и данных.

## Начать с окна или справки

| Задача | Что соединяется |
| --- | --- |
| [Показать памятку записи в окне заметок](/ru/recipes/basic/recording-reminder) | Условие по переднему окну и постоянный текст Text |
| [Различать сигналы открытия и закрытия просмотрщика](/ru/recipes/basic/viewer-open-close-cues) | Наличие окна, звуки в On Enter и On Exit |
| [Держать справочную карточку рядом с редактором](/ru/recipes/basic/reference-card) | Свой импортированный PNG, условие по переднему окну и размещение оверлея |
| [Ограничить клавишу уведомления приложением](/ru/recipes/basic/application-only-shortcut) | Отдельная аура состояния окна, Links перехвата клавиши и один сигнал |

Первой задаче достаточно окна заметок. Для карточки нужен свой читаемый PNG. В звуковых задачах выберите слышимые вам сигналы; для клавиши уведомления также нужна свободная клавиша в своих проверяемых окнах.

## Наблюдать визуальный источник

| Задача | Что соединяется |
| --- | --- |
| [Удерживать клавишу для проверки цветной панели](/ru/recipes/basic/hold-to-inspect) | Условие включения папки, ограниченный Color Search и текстовый ответ |
| [Услышать сигнал о своём значке готовности](/ru/recipes/basic/ready-icon-alert) | Захваченный источник, обрезанный образец и звук в On Enter |
| [Следить за предупреждающим цветом, работая в другом окне](/ru/recipes/basic/off-focus-color-indicator) | Отдельно выбранное окно захвата, сравнение цвета и видимое напоминание |
| [Наблюдать живую область состояния](/ru/recipes/basic/live-status-crop) | Собственный источник и область Replica, наличие окна и размещение копии |

Перед визуальной проверкой убедитесь, что выбранный источник отдаёт текущие пиксели в нужном состоянии окна. Совпадение изображения, сравнение среднего цвета и живая копия отвечают на разные вопросы. Для этих задач не нужно отправлять клавиши или нажимать в найденной области.

## Управлять своим состоянием и локальным набором

| Задача | Что соединяется |
| --- | --- |
| [Показывать предупреждение, пока сохранённый список содержит TODO](/ru/recipes/basic/checklist-file-warning) | Снимок файла UTF-8, сопоставление текста и видимая памятка |
| [Переводить подсказки в режим обслуживания](/ru/recipes/basic/maintenance-status-board) | Одно ручное состояние, ожидаемые состояния связей и разрешение папки |
| [Подать сигналы начала и конца короткого сценария](/ru/recipes/basic/two-stage-audible-cue) | Готовые звуковые действия, конечный макрос и пауза 1500 мс |
| [Скопировать подсказки, не заменяя оригинал](/ru/recipes/basic/copy-own-reminder-set) | Локальный JSON, Import Preview, Copy и проверка связей |

Задачам файла и копирования нужна доступная для записи локальная папка. Обслуживание использует только ваше состояние и Text; короткой цепочке также нужны шаблоны Macro и слышимый звук. Скрипты не требуются. Для общего захвата, OCR и управляемых маршрутов дерева переходите к [рецептам среднего уровня](/ru/recipes/intermediate).

Вернитесь в [Рецепты](/ru/recipes) для выбора по результату или на [главную](/ru/home) для обзора возможностей.
