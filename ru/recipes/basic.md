# Получить полезный результат без кода

Здесь всё собирается в обычных редакторах аур, триггеров, действий и оверлеев. Рецепты не зависят друг от друга: в каждом есть свои требования и вся настройка. Хватит небольшого набора аур, своих окон и своих данных.

## Начать с окна или справки

| Задача | Что соединяется |
| --- | --- |
| [Показать памятку записи в окне заметок](/ru/recipes/basic/recording-reminder) | Условие по переднему окну и постоянный текст Text |
| [Различать сигналы открытия и закрытия просмотрщика](/ru/recipes/basic/viewer-open-close-cues) | Наличие окна, звуки в On Enter и On Exit |
| [Держать справочную карточку рядом с редактором](/ru/recipes/basic/reference-card) | Свой PNG, условие по переднему окну и размещение оверлея |
| [Ограничить клавишу уведомления приложением](/ru/recipes/basic/application-only-shortcut) | Отдельная аура с состоянием окна, Links в перехвате клавиши и один сигнал |

Для первой задачи хватит окна заметок. Для карточки нужен свой читаемый PNG. Для звуковых задач выберите сигналы, которые вы точно услышите. Для клавиши уведомления нужна ещё клавиша, свободная в окнах, где вы проверяете.

## Наблюдать визуальный источник

| Задача | Что соединяется |
| --- | --- |
| [Удерживать клавишу для проверки цветной панели](/ru/recipes/basic/hold-to-inspect) | Условие включения папки, Color Search по небольшой области и текстовый ответ |
| [Услышать сигнал о своём значке готовности](/ru/recipes/basic/ready-icon-alert) | Захват окна, вырезанный образец и звук в On Enter |
| [Следить за предупреждающим цветом, работая в другом окне](/ru/recipes/basic/off-focus-color-indicator) | Отдельно выбранное окно захвата, сравнение цвета и видимое напоминание |
| [Наблюдать живую область состояния](/ru/recipes/basic/live-status-crop) | Свой источник и область Replica, наличие окна и размещение копии |

Сначала убедитесь, что источник отдаёт свежую картинку в том состоянии окна, которое вам нужно. Совпадение изображения, сравнение среднего цвета и живая копия отвечают на разные вопросы. В этих задачах не нужно отправлять клавиши или нажимать в найденной области.

| Задача | Что соединяется |
| --- | --- |
| [Показывать предупреждение, пока сохранённый список содержит TODO](/ru/recipes/basic/checklist-file-warning) | Файл UTF-8, поиск текста и видимая памятка |
| [Переводить подсказки в режим обслуживания](/ru/recipes/basic/maintenance-status-board) | Один ручной переключатель, связи с нужным состоянием и условие включения папки |
| [Подать сигналы начала и конца короткого сценария](/ru/recipes/basic/two-stage-audible-cue) | Готовые звуковые действия, конечный макрос и пауза 1500 мс |
| [Скопировать подсказки, не заменяя оригинал](/ru/recipes/basic/copy-own-reminder-set) | Локальный JSON, Import Preview, Copy и проверка связей |

Для задач с файлом и копированием нужна локальная папка, в которую можно писать. Режиму обслуживания хватит вашего переключателя и Text. Короткому сценарию нужны ещё шаблоны Macro и звук, который вы услышите. Скрипты не требуются. За общим захватом, OCR и управляемыми маршрутами дерева идите в [рецепты среднего уровня](/ru/recipes/intermediate).
