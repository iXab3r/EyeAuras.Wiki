# Наблюдать типизированный счётчик до Stop

Пока скрипт работает, в **Event Log** видны изменения известного счётчика. Число хранится у вашей ауры, а наблюдение и цикл принадлежат одному запуску.

1. Через **Add new → New Aura** создайте редактируемую тестовую ауру `RecipeCounter`. В **Actions → On Enter** добавьте **C# Script**. Для опыта используйте его ручную кнопку **Run**, без автоматической активации и других действий, меняющих счётчик.
2. Возьмите новое имя переменной `recipeSessionCounter`, не занятое у этой ауры и её предков. Полностью замените верхнеуровневый **Script.csx** приведённым файлом. Дополнительный пакет в этом хосте скриптов EyeAuras не нужен.
3. Дождитесь компиляции, нажмите **Run**, откройте **Event Log** действия. Наблюдение сначала сообщит `0`, затем `1`, `2`, `3`: цикл записывает новое число после каждой паузы 1000 мс.
4. Нажмите **Stop**. Отменяемая пауза завершится, появится `Counter stopped`, а выход из блока освободит подписку. Следующий **Run** явно начнёт новый сеанс с `0`.

| Выбор | Что означает |
| --- | --- |
| `AuraTree.Aura` | Аура, содержащая это действие C# Script; пример требует именно такого контекста. |
| `Variables.Get<int>(owner, "recipeSessionCounter")` | Типизированное обращение к целочисленной записи выбранного владельца, не новый отдельный контейнер. |
| `counter.Listen()` | Читает текущее значение и наблюдает отличающиеся изменения этого имени. |
| `1000` | Миллисекунды между записями после завершения очередной паузы; это не гарантия точных часов. |

## Script.csx

```csharp
using System;
using System.Reactive.Linq;
using System.Threading.Tasks;

{
    var owner = AuraTree.Aura;
    var counter = Variables.Get<int>(owner, "recipeSessionCounter");
    counter.Value = 0;
    using var observer = counter.Listen().Subscribe(
        value => Log.Info($"Observed counter: {value}"));
    try
    {
        while (true)
        {
            await Task.Delay(1000, cancellationToken);
            counter.Value++;
        }
    }
    catch (OperationCanceledException) when (cancellationToken.IsCancellationRequested)
    {
        Log.Info("Counter stopped");
    }
}
```


Целое число относится к простым значениям конфигурации: оно может пережить перекомпиляцию и сохраняться с настройками ауры. Здесь каждый Run намеренно сбрасывает его. Stop не удаляет запись; последнее число можно посмотреть в **Variables** ауры. Обычная локальная C#-переменная имела бы другой срок жизни.

Аура и типизированное обращение к переменной заимствованы; освобождать ауру не нужно. Пример владеет только подпиской `Listen()`. Ожидание цикла удерживает её до Stop. Отдельное изменение этой переменной также может попасть в журнал во время работы цикла.

[Сроки жизни переменных](/ru/scripting/examples/basic/variables) помогают выбрать хранилище, а [поиск своей ауры](/ru/scripting/examples/basic/find-aura) — явно выбрать того же владельца из другого скрипта. Запись влияет только на потребителей, которые действительно читают значение или используют привязку. `Log`, `AuraTree`, `Variables` и `cancellationToken` здесь принадлежат верхнеуровневому скрипту, а не обычному классу или Razor-компоненту.
