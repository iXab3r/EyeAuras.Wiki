# Наблюдать типизированный счётчик до Stop

Пока скрипт работает, в **Event Log** видно, как меняется счётчик. Число хранится в переменной вашей ауры. Наблюдение и цикл живут в пределах одного запуска.

1. Через **Add new → New Aura** создайте редактируемую тестовую ауру `RecipeCounter`. В **Actions → On Enter** добавьте **C# Script**. Запускайте его вручную кнопкой **Run**. Автоматическая активация и другие действия, которые меняют счётчик, здесь не нужны.
2. Возьмите новое имя переменной `recipeSessionCounter`, не занятое у этой ауры и её предков. Целиком замените верхнеуровневый **Script.csx** кодом ниже. Дополнительный пакет не нужен.
3. Дождитесь компиляции, нажмите **Run** и откройте **Event Log** действия. Сначала появится `0`, затем `1`, `2`, `3`: цикл записывает новое число после каждой паузы в 1000 мс.
4. Нажмите **Stop**. Пауза прервётся, появится `Counter stopped`, а при выходе из блока подписка освободится. Следующий **Run** снова начнёт с `0`.

| Выбор | Что означает |
| --- | --- |
| `AuraTree.Aura` | Аура, в которой находится это действие C# Script. Пример работает только в таком контексте. |
| `Variables.Get<int>(owner, "recipeSessionCounter")` | Типизированный доступ к целочисленной переменной выбранного владельца. Новый отдельный контейнер не создаётся. |
| `counter.Listen()` | Читает текущее значение и сообщает, когда значение этой переменной меняется на другое. |
| `1000` | Миллисекунды между записями, считая от конца очередной паузы. Точность часов не гарантируется. |

## Script.csx

```csharp
using System;
using System.Reactive.Linq;
using System.Threading.Tasks;

{
    var owner = AuraTree.Aura;
    var counter = Variables.Get<int>(owner, "recipeSessionCounter");
    counter.Value = 0;
    using var observer = counter.Listen().Subscribe(
        value => Log.Info($"Observed counter: {value}"));
    try
    {
        while (true)
        {
            await Task.Delay(1000, cancellationToken);
            counter.Value++;
        }
    }
    catch (OperationCanceledException) when (cancellationToken.IsCancellationRequested)
    {
        Log.Info("Counter stopped");
    }
}
```


Целое число — простое значение конфигурации: оно может пережить перекомпиляцию и сохраняться вместе с настройками ауры. Здесь каждый Run намеренно его сбрасывает. Stop запись не удаляет: последнее число видно в **Variables** ауры. У обычной локальной переменной C# срок жизни был бы другим.

Ауру и доступ к переменной скрипт только берёт у хоста, освобождать ауру не нужно. Своя у примера только подписка `Listen()`. Цикл держит её до Stop. Если эту переменную в это время изменит что-то ещё, это тоже может попасть в журнал.

Какое хранилище выбрать — в [Сроках жизни переменных](/ru/scripting/examples/basic/variables). Как из другого скрипта явно выбрать того же владельца — в [поиске своей ауры](/ru/scripting/examples/basic/find-aura). Запись влияет только на тех, кто действительно читает значение или использует привязку. `Log`, `AuraTree`, `Variables` и `cancellationToken` здесь есть у верхнеуровневого скрипта, но не у обычного класса или Razor-компонента.
