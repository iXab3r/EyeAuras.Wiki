# Соединить общий источник с управляемым результатом

Выбирайте эти задачи, когда уже умеете создавать ауру и хотите согласовать несколько частей: общий выбор захвата, отбор OCR-текста или намеренно управляемый маршрут дерева поведения. Каждый рецепт содержит собственную настройку.

| Ваша цель | Рецепт и необходимые условия |
| --- | --- |
| Менять источник двух визуальных проверок в одном месте | [Общий выбор захвата](/ru/recipes/intermediate/shared-capture-target): два своих различимых окна и работающий захват |
| Прочитать видимую строку перед показом памятки | [Строка состояния документа](/ru/recipes/intermediate/own-document-status-text): читаемый несекретный документ и доступные английские движок/язык OCR |
| Разрешить уведомление только после своей проверки | [Проверка перед уведомлением](/ru/recipes/intermediate/check-before-notify): шаблоны Behavior Tree, ручная аура состояния и одно звуковое действие |
| Повторять проверку до завершения одного управляемого прохода | [Повтор готовности](/ru/recipes/intermediate/retry-readiness-check): Until Success и ручные тики того же выбранного дерева |
| Выдержать наблюдаемое предупреждение перед сигналом | [Выдержка предупреждения](/ru/recipes/intermediate/stable-warning-state): ручная аура состояния, Debounce и слышимый аудиовыход |
| Прервать и заново начать ожидание на следующем тике | [Прервать своё ожидание](/ru/recipes/intermediate/cancel-owned-wait): Interrupter, стоп-аура и ручной Wait2000 мс |
| Выбрать основной сигнал или запасной | [Выбор запасного сигнала](/ru/recipes/intermediate/choose-a-fallback-cue): Selector, управляемые проверки и два разных звука |
| Найти слой, скрывающий связанную памятку | [Разбор связанной памятки](/ru/recipes/intermediate/trace-dependent-reminder): свой связанный набор Text и привязка свойства |
| Сопоставить импульс с записями переходов | [Разбор переходов Timer](/ru/recipes/intermediate/inspect-timer-transitions): равные1000/1000 мс Timer, Text и Event Viewer |
| Сохранить данные сбоя до возврата профиля | [Отчёт перед восстановлением](/ru/recipes/intermediate/report-before-rollback): свой профиль, локальные копии и известный снимок истории |
| Сравнить половинные полоски разных размеров | [Доля цвета при другом размере](/ru/recipes/intermediate/color-coverage-across-sizes): свои откалиброванные двухцветные полоски и работающий захват |
| Решить, понятны ли необходимые условия набора | [Проверка до импорта/включения](/ru/recipes/intermediate/review-import-before-enable): изучаемый файл либо доступная публикация с требованиями |

Задача общего источника заканчивается двумя предпросмотрами нужного окна; условия распознавания остаются отдельными. Задача OCR сначала проверяет реально прочитанные слова. Два рецепта дерева различают завершившуюся неуспешную ветку и сохранённый повтор Running; для управляемых примеров автоматическое исполнение выключено.

Для прямой памятки или первого локального набора начните с [базовых рецептов](/ru/recipes/basic). В [Рецептах](/ru/recipes) можно выбрать задачу по конечному результату. Одного имени источника, пакета или шаблона недостаточно для готовности недоступного захвата либо OCR: учитывайте условия каждого рецепта.
