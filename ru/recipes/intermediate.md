# Соединить общий источник с управляемым результатом

Эти рецепты — для тех, кто уже умеет создавать ауру и хочет связать несколько частей: общий выбор захвата, отбор текста OCR или дерево поведения, которое вы запускаете вручную.

| Ваша цель | Рецепт и что для него нужно |
| --- | --- |
| Менять источник двух визуальных проверок в одном месте | [Общий выбор захвата](/ru/recipes/intermediate/shared-capture-target): два своих окна, которые легко различить, и работающий захват |
| Прочитать видимую строку перед показом памятки | [Строка состояния документа](/ru/recipes/intermediate/own-document-status-text): читаемый несекретный документ, доступные движок OCR и английский язык для него |
| Разрешить уведомление только после своей проверки | [Проверка перед уведомлением](/ru/recipes/intermediate/check-before-notify): шаблоны Behavior Tree, ручная аура состояния и одно звуковое действие |
| Повторять проверку, пока не завершится один управляемый проход | [Повтор готовности](/ru/recipes/intermediate/retry-readiness-check): Until Success и ручные тики того же дерева |
| Выдержать предупреждение перед сигналом | [Выдержка предупреждения](/ru/recipes/intermediate/stable-warning-state): ручная аура состояния, Debounce и слышимый аудиовыход |
| Прервать ожидание и начать его заново на следующем тике | [Прервать своё ожидание](/ru/recipes/intermediate/cancel-owned-wait): Interrupter, стоп-аура и ручной Wait 2000 мс |
| Выбрать основной сигнал или запасной | [Выбор запасного сигнала](/ru/recipes/intermediate/choose-a-fallback-cue): Selector, управляемые проверки и два разных звука |
| Найти слой, который скрывает связанную памятку | [Разбор связанной памятки](/ru/recipes/intermediate/trace-dependent-reminder): свой связанный набор Text и привязка свойства |
| Сопоставить импульс с записями переходов | [Разбор переходов Timer](/ru/recipes/intermediate/inspect-timer-transitions): Timer с равными 1000/1000 мс, Text и Event Viewer |
| Сохранить данные сбоя до возврата профиля | [Отчёт перед восстановлением](/ru/recipes/intermediate/report-before-rollback): свой профиль, локальные копии и известный снимок истории |
| Сравнить половинные полоски разных размеров | [Доля цвета при другом размере](/ru/recipes/intermediate/color-coverage-across-sizes): свои откалиброванные двухцветные полоски и работающий захват |
| Понять, ясны ли условия набора | [Проверка до импорта/включения](/ru/recipes/intermediate/review-import-before-enable): файл, который вы изучаете, либо доступная публикация с требованиями |

Если нужна простая памятка или первый локальный набор, начните с [базовых рецептов](/ru/recipes/basic). В [Рецептах](/ru/recipes) задачу можно выбрать по конечному результату.
