# Рецепты для разработчиков

Каждый рецепт — небольшой проект на ваших данных. Все файлы приведены целиком и с именами. Видно, что лежит в верхнеуровневом скрипте, что в обычных классах и что в Razor-компонентах. Начните со счётчика в журнале, потом добавляйте окно, ресурсы проекта или отдельную нативную отрисовку.

| Что получится | Рецепт |
| --- | --- |
| Следите за переменной своей ауры, увеличиваете её раз в секунду и освобождаете подписку при остановке. | [Наблюдать типизированный счётчик до Stop](/ru/recipes/developer/typed-counter-observation) |
| Упаковываете текст и свой PNG вместе со скриптом, читаете текст через файловый сервис и показываете оба ресурса в своём окне. | [Вложить справку и своё изображение в проект](/ru/recipes/developer/bundle-own-reference-resources) |
| Выносите оформление счётчика в C#-класс, правите экспортированное решение и запускаете импортированный результат в EyeAuras. | [Редактировать экспортированный проект с обычным классом](/ru/recipes/developer/ide-project-with-helper) |
| Следите за загруженным Hotkey Is Active, переключаете его из Razor и оформляете текущее значение CSS-файлом проекта. | [Сделать оформленную панель своего триггера](/ru/recipes/developer/reactive-aura-control-panel) |
| Импортируете ES-модуль после отрисовки, передаёте один ElementReference и освобождаете модуль вместе с компонентом. | [Подсветить свой элемент модулем проекта](/ru/recipes/developer/project-module-highlight) |
| Показываете свой ограниченный список через ImGuiSdk 0.1.47 с настоящим TTF и локальным выбором шрифта до Stop. | [Вывести 50 известных показателей своим шрифтом](/ru/recipes/developer/native-font-telemetry-panel) |
| Читаете позиции курсора в одном контексте ImGui, храните до 64 точек и освобождаете отрисовку по Stop. | [Оставить ограниченный след своего курсора](/ru/recipes/developer/cursor-trail-cleanup) |
| Отдельно прогреваете захват, измеряете десять новых поисков, затем десять раз считаете пиксели одной своей копии. | [Отделить захват CV от десяти проходов по кадру](/ru/recipes/developer/profile-cv-without-input) |
| Собираете свой маленький процесс, получаете его живые PID и адрес и читаете объявленное целое типизированным API. | [Прочитать Int32 своего подготовленного процесса](/ru/recipes/developer/read-owned-process-scalar) |
| Явно регистрируете неизменяемый снимок и controller, читаете локальный GET и останавливаете хост вместе со скриптом. | [Выдать своё состояние только через loopback GET](/ru/recipes/developer/localhost-status-controller) |
| Создаёте настоящий HTML-файл, читаете ячейки отдельным сеансом Selenium 4.24.0 и завершаете его через Quit. | [Прочитать известные ячейки своего локального HTML](/ru/recipes/developer/read-local-html-table) |
| Проверяете свои кадры, заканчиваете разметку, обучаете и экспортируете совместимый детектор и смотрите рамки без ввода. | [Обучить свой проверенный детектор и увидеть рамки](/ru/recipes/developer/own-detector-to-boxes) |

Для окон нужен совместимый настольный хост Blazor/WebView2. В рецепте ImGui отдельно указаны версия SDK и нативные требования. Ссылка на пакет сама не регистрирует все сервисы.
