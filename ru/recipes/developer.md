# Рецепты для разработчиков

Выберите небольшой проект со своими данными. В каждом рецепте есть полные именованные файлы и разделены верхнеуровневый скрипт, обычные классы и Razor-компоненты. Начните со счётчика в журнале, затем добавляйте окно, ресурсы проекта или отдельный нативный механизм отрисовки.

| Что получится | Рецепт |
| --- | --- |
| Наблюдайте переменную своей ауры, увеличивайте её раз в секунду и освобождайте подписку при остановке. | [Наблюдать типизированный счётчик до Stop](/ru/recipes/developer/typed-counter-observation) |
| Упакуйте текст и собственный PNG со скриптом, прочитайте текст через файловый сервис и покажите оба ресурса в своём окне. | [Вложить справку и своё изображение в проект](/ru/recipes/developer/bundle-own-reference-resources) |
| Вынесите оформление счётчика в C#-класс, измените экспортированное решение и запустите импортированный результат в EyeAuras. | [Редактировать экспортированный проект с обычным классом](/ru/recipes/developer/ide-project-with-helper) |
| Наблюдайте загруженный Hotkey Is Active, переключайте его из Razor и оформляйте текущее значение CSS-файлом проекта. | [Сделать оформленную панель своего триггера](/ru/recipes/developer/reactive-aura-control-panel) |
| Импортируйте ES-модуль после отрисовки, передайте один ElementReference и освободите модуль вместе с компонентом. | [Подсветить свой элемент модулем проекта](/ru/recipes/developer/project-module-highlight) |
| Покажите ограниченный собственный список через ImGuiSdk 0.1.47 с настоящим TTF и локальным выбором шрифта до Stop. | [Вывести 50 известных показателей своим шрифтом](/ru/recipes/developer/native-font-telemetry-panel) |
| Читайте позиции курсора в одном контексте ImGui, храните до 64 точек и освобождайте отрисовку по Stop. | [Оставить ограниченный след своего курсора](/ru/recipes/developer/cursor-trail-cleanup) |
| Прогрейте захват отдельно, измерьте десять новых поисков, затем десять раз посчитайте пиксели одной собственной копии. | [Отделить захват CV от десяти проходов по кадру](/ru/recipes/developer/profile-cv-without-input) |
| Соберите маленький собственный процесс, получите его живые PID и адрес и прочитайте объявленное целое типизированным API. | [Прочитать Int32 своего подготовленного процесса](/ru/recipes/developer/read-owned-process-scalar) |
| Явно зарегистрируйте неизменяемый снимок и controller, прочитайте локальный GET и остановите хост вместе со скриптом. | [Выдать своё состояние только через loopback GET](/ru/recipes/developer/localhost-status-controller) |
| Создайте физический HTML-файл, прочитайте ячейки отдельным сеансом Selenium 4.24.0 и завершите его через Quit. | [Прочитать известные ячейки своего локального HTML](/ru/recipes/developer/read-local-html-table) |
| Проверьте собственные кадры, завершите разметку, обучите и экспортируйте совместимый детектор и осмотрите рамки без ввода. | [Обучить свой проверенный детектор и увидеть рамки](/ru/recipes/developer/own-detector-to-boxes) |

Для окон нужен совместимый настольный хост Blazor/WebView2; рецепт ImGui отдельно указывает версию SDK и нативные требования. Подготовьте свой PNG или TTF там, где это требуется. Ссылка на пакет не регистрирует все сервисы.
