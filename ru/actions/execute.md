# Execute Actions — повторно использовать готовую цепочку

Два сигнала с паузой могут понадобиться в нескольких аурах. Вместо копирования соберите эту цепочку один раз и вызывайте её действием Execute Actions. В старых версиях и по адресу этой статьи оно называется Execute Aura.

## Вызовите цепочку из другой ауры

1. Создайте ауру «Два сигнала». Добавьте в неё [Fixed Value](/ru/triggers/fixed-value) со значением **Is NOT Active**, чтобы она сама не запускала действия.
2. В её **On Enter** добавьте [Play Sound](/ru/actions/play-sound) со звуком Ping и выключенным Play in background, затем [Delay](/ru/actions/delay) на `1000` мс, затем Play Sound со звуком Bell. Остальные группы действий оставьте пустыми.
3. Создайте ауру «Проверка вызова» с Fixed Value в состоянии Is NOT Active. В её On Enter добавьте **Execute Actions**.
4. В **Aura links** нажмите **Links** и выберите ауру «Два сигнала». В **Execute actions** задайте `1`, а в **Strategy** выберите **Run 1-by-1 in order of addition**.
5. В ауре «Проверка вызова» переключите Fixed Value в Is Active и дождитесь конца цепочки.

Прозвучат Ping, пауза и Bell. Аура «Два сигнала» при этом останется неактивной: Execute Actions вызывает её действия напрямую, без изменения её триггера. Теперь такую же ссылку можно добавить в другую ауру.

Чтобы вызвать готовую цепочку из дерева поведения, используйте [Run Aura](/ru/behavior-trees/nodes/execute-aura). Если вызов должен зависеть от состояния исходной ауры, отдельно проверьте его через [Aura Is Active](/ru/behavior-trees/nodes/aura-is-active): сам вызов действий это состояние не проверяет.

## Настройки

| Настройка | Что делает |
| --- | --- |
| Aura links / Links | Выбирает ауры, из которых будут взяты действия. Для первого примера достаточно одной ссылки. |
| Execute actions, time(s) | Число повторов. `1` выполняет выбранную стратегию один раз, `0` не выполняет её. |
| Strategy — Run 1-by-1 in order of addition | Выполняет действия последовательно, ожидая завершения каждого. Для каждой связанной ауры берутся группы On Enter, While Active и On Exit в этом порядке. |
| Strategy — Run one random linked action | На каждом повторе выбирает одно случайное действие из всех связанных аур. Это выбор отдельного действия, а не целой цепочки одной ауры. |

Выполняются действия **из всех трёх групп**, а не только из On Enter. Поэтому в примере две другие группы пусты. Ошибка действия прерывает последовательный вызов; звук, запущенный в фоне, сам по себе не задерживает следующее действие.

Порядок отображения ссылок в редакторе может отличаться от порядка выполнения. Если порядок важен, храните одну цепочку в одной ауре. Не замыкайте вызовы по кругу через другие ауры.
