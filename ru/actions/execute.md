# Execute Actions — повторно использовать готовую цепочку

Execute Actions запускает действия другой ауры. Соберите цепочку один раз — например, два сигнала с паузой — и вызывайте её из нескольких аур вместо копирования. В старых версиях и в адресе этой статьи действие называется Execute Aura.

## Вызовите цепочку из другой ауры

1. Создайте ауру «Два сигнала». Добавьте в неё [Fixed Value](/ru/triggers/fixed-value) со значением **Is NOT Active**, чтобы она не запускала действия сама.
2. В её **On Enter** добавьте [Play Sound](/ru/actions/play-sound) со звуком Ping и выключенным Play in background, затем [Delay](/ru/actions/delay) на `1000` мс, затем Play Sound со звуком Bell. Остальные группы действий оставьте пустыми.
3. Создайте ауру «Проверка вызова» с Fixed Value в состоянии Is NOT Active. В её On Enter добавьте **Execute Actions**.
4. В **Aura links** нажмите **Links** и выберите ауру «Два сигнала». В **Execute actions** задайте `1`, в **Strategy** выберите **Run 1-by-1 in order of addition**.
5. В ауре «Проверка вызова» переключите Fixed Value в Is Active и дождитесь конца цепочки.

Прозвучат Ping, пауза и Bell. Аура «Два сигнала» при этом останется неактивной: Execute Actions вызывает её действия напрямую и её триггер не трогает.

Из дерева поведения готовую цепочку вызывает узел [Run Aura](/ru/behavior-trees/nodes/execute-aura). Сам вызов не смотрит, активна ли исходная аура. Если это важно, проверьте её отдельно через [Aura Is Active](/ru/behavior-trees/nodes/aura-is-active).

## Настройки

| Настройка | Что делает |
| --- | --- |
| Aura links / Links | Ауры, из которых берутся действия. |
| Execute actions, time(s) | Число повторов. `1` выполняет выбранную стратегию один раз, `0` не выполняет её. |
| Strategy — Run 1-by-1 in order of addition | Выполняет действия по очереди и ждёт завершения каждого. У каждой связанной ауры берутся группы On Enter, While Active и On Exit — в этом порядке. |
| Strategy — Run one random linked action | На каждом повторе выбирает одно случайное действие из всех связанных аур. Именно одно действие, а не целую цепочку одной ауры. |

Выполняются действия **из всех трёх групп**, а не только из On Enter. Поэтому в примере две другие группы пустые. Ошибка в действии прерывает последовательный вызов. Звук, запущенный в фоне, следующее действие не задерживает.

Ссылки в редакторе могут стоять не в том порядке, в каком выполняются. Если порядок важен, держите одну цепочку в одной ауре. Не замыкайте вызовы по кругу через другие ауры.
