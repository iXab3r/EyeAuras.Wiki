# Ввод через TetherScript Driver

TetherScript Driver — способ ввода через драйвер виртуальной клавиатуры и мыши Tetherscript. EyeAuras передаёт команды виртуальным HID-устройствам драйвера. Например, Send Sequence может так нажать F3 и открыть поиск в браузере.

Само приложение ControlMyJoystick для этого запускать не нужно. На схеме показан только путь ввода. Слово Game не означает встроенную интеграцию с какой-то игрой.

![EyeAuras передаёт ввод через драйвер целевому приложению](https://s3.eyeauras.net/media/2025/07/ChatGPT%20Image%20Jul%2014%2C%202025%2C%2003_09_58%20PM.png =x200)

## Что подготовить

Нужны EyeAuras со способом ввода **TetherScript Driver**, установленный совместимый драйвер Tetherscript и обычное окно, которое принимает клавиатуру. Для примера откройте в браузере страницу, где F3 открывает поиск. Начните с клавиатуры: если одно виртуальное устройство на месте, это ещё не проверяет все режимы мыши.

Если драйвера нет, возьмите [ControlMyJoystick на сайте производителя](https://tetherscript.com/controlmyjoystick-home/). Кнопка **Install...** у этого способа ввода открывает страницу загрузки, а после установки заново проверяет устройства. По [README производителя HVDK](https://github.com/tetherscript/hvdk), драйверы из пробной установки продолжают работать и без покупки ControlMyJoystick.

HVDK как отдельный продукт больше не поддерживается. [Зеркало HVDK Standard 2.1](https://s3.eyeauras.net/media/2024/10/HVDK%20Standard%202.1.exe) оставлено для старых установок. Это не значит, что он совместим с любой современной Windows. Требования и установку смотрите у производителя для своей версии драйвера. Если установщик просит перезагрузку, перезагрузитесь до настройки ввода.

## Выбрать драйвер и открыть поиск

1. Создайте тестовую ауру и добавьте **Send Sequence**. Через **Fn → F3** добавьте пару событий с задержкой между Down и Up.
2. В **Advanced input settings → Target Window** выберите окно браузера. В **Input Simulator** выберите **TetherScript Driver**.
3. Проверьте, что способ ввода готов. Если предлагается Install..., сначала доведите установку драйвера до конца. **Block User input** оставьте **None**, а **Key/Button State** включите.
4. Сделайте страницу текущей вкладкой и нажмите **Execute** у действия. Панель поиска должна открыться так же, как от F3 с клавиатуры. Если не открылась, проверьте выбранное окно, фокус и готовность виртуальной клавиатуры.
5. Закройте поиск вручную и повторите команду. Только после этого назначайте этот способ ввода остальным действиям.

На старом снимке раскрыт выбор способа ввода у Send Sequence. В текущем редакторе он тоже находится в Advanced input settings, но список выглядит иначе.

## Настроить область применения

| Где выбрать Input Simulator | На что влияет |
|---|---|
| Advanced input settings у Send Sequence | На это действие. Удобно для первой проверки |
| Folder Properties → Triggers/Actions/Overlays Defaults | На компоненты, которые берут значение по умолчанию из этой папки. У существующих действий проверьте привязки. Apply to All применяет выбранные свойства по области папки |
| Свойства корня Macro / Behavior Tree | На ввод, который использует настройки этого макроса или дерева. Это другой редактор, а не старое действие Send Text |

Настройка папки удобна, когда драйвером должна пользоваться вся группа. Не задавайте на разных уровнях значения, которые противоречат друг другу. Какие индивидуальные настройки будут заменены, объясняет статья про [наследование и Apply to All](/ru/features/default-properties).

В настройках папки включено поле Input Simulator и выбран способ ввода:

![Input Simulator в настройках папки](https://s3.eyeauras.net/media/2025/07/NVIDIA_Overlay_w4H6swrVSxeI4uGV.png =x400)

В макросе способ ввода выбирается в свойствах корневой строки, в дереве — в свойствах Root.

![Выбор способа ввода в свойствах корня макроса](https://s3.eyeauras.net/media/2025/07/NVIDIA_Overlay_N4kvjMqSsIqbaVhH.png =x600)

## Ограничения

| Особенность | Что учитывать |
|---|---|
| Виртуальные HID-устройства | EyeAuras использует драйверные устройства клавиатуры и абсолютной/относительной мыши. Доступа к внутренним данным приложения это не даёт |
| Target Window | Перед вводом целевое окно активируется. Драйвер не делает из обычной клавиатуры универсальный ввод в свёрнутое окно |
| Готовность | Проверка установки может найти клавиатуру или абсолютную мышь. Нужное вам действие всё равно проверяйте отдельно |
| Совместимость | Примет ли приложение ввод, зависит от него и его окружения. Работающий драйвер не значит, что он невидим или разрешён в любом приложении |

Если нужно физическое устройство, а не виртуальный драйвер, смотрите [Usb2Kbd](/ru/actions/sendinput/usb2kbd): у него другая подготовка и другой протокол. Способы доставки сравниваются в [общих параметрах](/ru/actions/sendinput/options).
