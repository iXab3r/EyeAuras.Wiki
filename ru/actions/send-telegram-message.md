# Send To Telegram — получить уведомление на телефон

Вы хотите узнать о событии, даже когда отошли от компьютера. Например, аура заметила надпись о потере соединения — EyeAuras присылает сообщение в Telegram, при необходимости со скриншотом.

Действие отправляет сообщение от бота. Само условие события задаётся триггерами ауры; отправка от имени вашего личного аккаунта не поддерживается.

## Сначала проверьте отправку

1. Создайте бота через [BotFather](https://t.me/BotFather): команда `/newbot`, затем имя и username бота. Сохраните выданный токен.
2. Добавьте в ауру действие Send To Telegram и заполните Telegram Bot Token.
3. Откройте личный чат с вашим ботом в Telegram и нажмите Start либо отправьте `/start`. В EyeAuras оставьте Chat Id пустым, найдите свой чат во входящей истории Chat Log и скопируйте его Chat Id в поле действия.
4. В Message text напишите «Проверка связи», выберите Message format — Text. Пока оставьте Attach screenshot выключенным.
5. Выполните действие. В чате с ботом должно появиться сообщение «Проверка связи».

Токен даёт доступ к боту: храните его как пароль. Подготовка бота описана также в [руководстве Telegram](https://core.telegram.org/bots/tutorial#obtain-your-bot-token).

## Подключите уведомление к событию

Поместите действие в **On Enter** нужной ауры. Оно отправит сообщение при переходе ауры в активное состояние. Например, условием может быть [найденная надпись](/ru/triggers/images/text-search).

Для разового уведомления не помещайте отправку в While Active: эта группа повторяет действия, пока аура активна.

## Настройки

| Настройка | Что указать |
| --- | --- |
| Telegram Bot Token | Токен бота от BotFather. |
| Chat Id | Чат получателя. При отправке обязателен; пустое поле используется на шаге определения чата. |
| Message text | Текст уведомления. |
| Message format | Для первой проверки — Text. HTML и Markdown требуют правил форматирования Telegram. |
| Attach screenshot | Добавляет снимок выбранного окна. Если окно не задано, захватывается рабочий стол. |
| Выбор окна | Окно для скриншота; на получателя сообщения не влияет. |
| Proxy server | Необязательный SOCKS5-прокси, формат `username:password@host:port`. |

## Если сообщение не пришло

Проверьте ошибку в истории действия, токен и Chat Id. Убедитесь, что вы начали чат с ботом и не заблокировали его. Для группы бот должен быть её участником и иметь возможность отправлять сообщения.

Если обычный текст отправляется, а сообщение с разметкой — нет, верните Text и проверьте [правила форматирования Telegram](https://core.telegram.org/bots/api#formatting-options).
