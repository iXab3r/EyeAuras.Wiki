# Send To Telegram — получить уведомление на телефон

Send To Telegram отправляет вам сообщение в Telegram, если нужно — со скриншотом. Так вы узнаете о событии, даже когда отошли от компьютера. Например, аура заметила надпись о потере соединения и написала вам.

Сообщение приходит от бота. Отправлять от вашего личного аккаунта нельзя. Когда отправлять, решают триггеры ауры.

## Сначала проверьте отправку

1. Создайте бота через [BotFather](https://t.me/BotFather): команда `/newbot`, затем имя и username бота. Сохраните выданный токен.
2. Чтобы узнать свой чат, создайте временную ауру с триггером Telegram Message. Укажите токен бота, Chat Id оставьте пустым и убедитесь, что аура включена.
3. Откройте в Telegram личный чат с ботом и отправьте `/start`. В истории триггера Message history найдите это сообщение и скопируйте Chat Id. Временную ауру теперь можно удалить.
4. Добавьте действие Send To Telegram в нужную ауру. Укажите Telegram Bot Token и полученный Chat Id. В Message text напишите «Проверка связи», в Message format выберите Text, Attach screenshot выключите.
5. Выполните действие. В чате с ботом должно появиться сообщение «Проверка связи».

Токен даёт доступ к боту, храните его как пароль. Как подготовить бота, описано и в [руководстве Telegram](https://core.telegram.org/bots/tutorial#obtain-your-bot-token).

## Подключите уведомление к событию

Положите действие в **On Enter** нужной ауры. Сообщение уйдёт, когда аура станет активной. Условием может быть, например, [найденная надпись](/ru/triggers/images/text-search).

Для разового уведомления не кладите отправку в While Active: эта группа повторяет действия, пока аура активна.

## Настройки

| Настройка | Что указать |
| --- | --- |
| Telegram Bot Token | Токен бота от BotFather. |
| Chat Id | Идентификатор чата получателя. Без него сообщение не отправится. |
| Message text | Текст уведомления. |
| Message format | Для первой проверки — Text. Для HTML и Markdown нужно соблюдать правила форматирования Telegram. |
| Attach screenshot | Добавляет снимок выбранного окна. Если окно не задано, снимается рабочий стол. |
| Window to screenshot | Окно для скриншота. На получателя сообщения не влияет. |
| Proxy server | Необязательный SOCKS5-прокси, формат `username:password@host:port`. |

## Если сообщение не пришло

Посмотрите ошибку в истории действия, проверьте токен и Chat Id. Убедитесь, что вы начали чат с ботом и не заблокировали его. В группе бот должен быть участником и иметь право отправлять сообщения.

Если обычный текст отправляется, а сообщение с разметкой — нет, верните Text и проверьте [правила форматирования Telegram](https://core.telegram.org/bots/api#formatting-options).
