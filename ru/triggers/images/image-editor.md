# Редактор шаблона изображения

Если рядом с нужным значком меняется подпись или фон, не включайте их в шаблон Image Search. Во встроенном редакторе можно оставить сам значок, убрать лишние пиксели и сохранить подготовленный образец прямо в триггер.

Редактор изменяет **сохранённый шаблон**. [Image Effects](/ru/triggers/images/effects) обрабатывают **каждый захваченный кадр** перед поиском. Выбирайте инструмент по тому, какую из двух картинок нужно изменить.

## Оставить значок и исключить фон

Нужен триггер **Image Search** с уже загруженным изображением: через **Load...**, буфер обмена или **Load from Preview Pane**. Для примера выберите значок на однотонном фоне; если фон неоднородный, используйте Crop и Erase без удаления всего цвета.

1. В **Template source — what to search for** нажмите **Edit...**.
2. Выберите **Crop**. Подгоните рамку под значок, исключив подпись и соседние элементы, затем нажмите **Apply crop**. Колесо мыши меняет масштаб просмотра; изображение можно перемещать внутри области обрезки.

   На снимке рамка оставляет изображение фламинго и отсекает большую часть пустого поля:

   ![Рамка Crop вокруг полезной части шаблона](https://s3.eyeauras.net/media/2026/03/EyeAuras_2GV7n4SiIU.png =x700)

3. Выберите **Remove Color**. Начните с **Tolerance = 0%**, нажмите на пиксель однотонного фона. Если остались близкие оттенки, немного увеличьте Tolerance и повторите выбор. Большой допуск может удалить часть значка.

   Шахматный фон на снимке означает прозрачность. Такие пиксели Image Search исключает из сравнения:

   ![Remove Color и прозрачный фон](https://s3.eyeauras.net/media/2026/03/EyeAuras_GzpbgEXA4d.png =x700)

4. Если остались отдельные лишние детали, выберите **Erase**, задайте подходящий **Brush size** и сотрите их. Сохраните характерные линии и достаточно непрозрачных пикселей самого значка.
5. Ошибочное изменение отмените через **Undo** или **Ctrl+Z**. Вернуть отменённое можно через **Redo** или **Ctrl+Y**.
6. Нажмите **Save** внизу окна. Шаблон в триггере должен обновиться. Затем в Image Search нажмите **Refresh Once** и проверьте совпадение на кадре со значком и без него.

Снимки показывают редактор образца, а не отдельный распознаватель объектов. Прозрачный фон исключает ненужное из сравнения, но не делает оставшуюся часть шаблона устойчивой к любому масштабу и повороту.

## Когда менять размер

Если размер шаблона отличается от значка в захваченном кадре, откройте **Resize**. Лучше сначала взять образец из самого кадра: так легче сохранить одинаковый масштаб.

| Настройка Resize | Как использовать |
|---|---|
| 50%, 75%, 100%, 125%, 150%, 200% | Готовый масштаб шаблона |
| Width / Height | Точный размер в пикселях |
| Scale | Масштаб в процентах |
| Keep aspect ratio | Сохраняет пропорции; включён по умолчанию. Обычно его стоит оставить |
| Apply | Применяет выбранный размер к шаблону |
| Reset | Сбрасывает параметры изменения размера до текущего изображения |

![Параметры Resize и сохранение пропорций](https://s3.eyeauras.net/media/2026/03/EyeAuras_bkvQJXOPqM.png =x700)

Уменьшение только шаблона не уменьшает значок в исходном окне. Если используете эффекты изменения размера кадра, подбирайте образец под их результат.

<details>
<summary>Остальные инструменты и сохранение</summary>

| Элемент | Назначение |
|---|---|
| Erase → Brush size | Стирает пиксели кистью, делая их прозрачными |
| Remove Color → Tolerance | Допуск сходства с выбранным пикселем; удаление действует на похожие цвета изображения, а не только на соседний фон |
| Adjust → Brightness / Contrast / Saturation | Меняет яркость, контраст и насыщенность образца. Нажмите Apply, чтобы применить; Reset сбрасывает параметры коррекции |
| Fit / 1:1 | Меняет масштаб просмотра, а не размеры сохранённого шаблона |
| Save | Применяет результат к триггеру; незавершённая обрезка тоже сохраняется |
| Cancel | Закрывает редактор без применения результата к триггеру |

Если фон и значок имеют один цвет, Remove Color может удалить оба. В таком случае отмените операцию и оставьте фон либо сотрите только отдельные участки кистью.

</details>

Файл, из которого когда-то загрузили образец, при Save не перезаписывается. Для отдельной копии используйте **Save...** в самом [Image Search](/ru/triggers/images/image-search).
