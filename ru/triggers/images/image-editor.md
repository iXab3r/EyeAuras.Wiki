# Редактор шаблона изображения

Во встроенном редакторе готовят шаблон для Image Search: оставляют сам значок, убирают лишние пиксели и сохраняют результат прямо в триггер. Это нужно, когда рядом со значком меняется подпись или фон — в шаблон они попадать не должны.

Редактор меняет **сохранённый шаблон**. [Image Effects](/ru/triggers/images/effects) обрабатывают **каждый захваченный кадр** перед поиском. Выбирайте инструмент по тому, какую из двух картинок нужно изменить.

## Оставить значок и исключить фон

Нужен триггер **Image Search**, в который уже загружено изображение: через **Load...**, буфер обмена или **Load from Preview Pane**. Для примера возьмите значок на однотонном фоне. Если фон неоднородный, работайте через Crop и Erase и не удаляйте цвет целиком.

1. В **Template source — what to search for** нажмите **Edit...**.
2. Выберите **Crop**. Подгоните рамку под значок, чтобы подпись и соседние элементы остались снаружи, и нажмите **Apply crop**. Колесо мыши меняет масштаб просмотра. Изображение можно двигать внутри области обрезки.

   ![В редакторе выбран Crop, синяя рамка охватывает фламинго, справа кнопка Apply crop](/assets/callouts/batch2/ru/template-editor-crop.png =x700)

3. Выберите **Remove Color**. Начните с **Tolerance = 0%** и нажмите на пиксель однотонного фона. Если остались близкие оттенки, немного увеличьте Tolerance и нажмите ещё раз. Большой допуск может удалить часть значка.

   Шахматный фон на снимке — это прозрачность. Такие пиксели Image Search не сравнивает:

   ![В Remove Color указан допуск 20% и выбран розовый цвет, на части фламинго видна шахматная сетка прозрачности](/assets/callouts/batch2/ru/template-editor-remove-color.png =x700)

4. Если остались отдельные лишние детали, выберите **Erase**, задайте **Brush size** и сотрите их. Сохраните характерные линии и достаточно непрозрачных пикселей самого значка.
5. Ошиблись — нажмите **Undo** или **Ctrl+Z**. Вернуть отменённое можно через **Redo** или **Ctrl+Y**.
6. Нажмите **Save** внизу окна. Шаблон в триггере должен обновиться. Затем в Image Search нажмите **Refresh Once** и проверьте совпадение на кадре со значком и без него.

## Когда менять размер

Если шаблон по размеру отличается от значка в захваченном кадре, откройте **Resize**. Лучше сразу взять образец из самого кадра: так проще сохранить одинаковый масштаб.

| Настройка Resize | Как использовать |
|---|---|
| 50%, 75%, 100%, 125%, 150%, 200% | Готовый масштаб шаблона |
| Width / Height | Точный размер в пикселях |
| Scale | Масштаб в процентах |
| Keep aspect ratio | Сохраняет пропорции. Включён по умолчанию, обычно его стоит оставить |
| Apply | Применяет выбранный размер к шаблону |
| Reset | Сбрасывает параметры изменения размера до текущего изображения |

![В Resize заданы ширина 2401 и высота 1162 пикселя, флажок Keep aspect ratio включён](/assets/callouts/batch2/ru/template-editor-resize.png =x700)

Если вы меняете размер кадра эффектами, подбирайте образец под их результат.

<details>
<summary>Остальные инструменты и сохранение</summary>

| Элемент | Назначение |
|---|---|
| Erase → Brush size | Стирает пиксели кистью, они становятся прозрачными |
| Remove Color → Tolerance | Насколько цвет может отличаться от выбранного пикселя. Удаляются похожие цвета по всему изображению, а не только соседний фон |
| Adjust → Brightness / Contrast / Saturation | Меняет яркость, контраст и насыщенность образца. Apply применяет изменения, Reset сбрасывает параметры коррекции |
| Fit / 1:1 | Меняет масштаб просмотра, а не размер сохранённого шаблона |
| Save | Сохраняет результат в триггер. Незавершённая обрезка тоже сохраняется |
| Cancel | Закрывает редактор, триггер не меняется |

Если фон и значок одного цвета, Remove Color может удалить оба. Тогда отмените операцию и оставьте фон либо сотрите кистью только отдельные участки.

</details>

Файл, из которого вы когда-то загрузили образец, при Save не перезаписывается. Чтобы получить отдельную копию, нажмите **Save...** в самом [Image Search](/ru/triggers/images/image-search).
