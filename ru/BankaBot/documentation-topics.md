# Найти нужную тему BankaBot

Чтобы не искать настройку маршрута среди правил подсветки, начните с задачи, которую хотите решить. Раздел относится к отдельной поставке BankaBot для Lineage 2; его историческое описание не заменяет инструкцию к имеющейся у вас версии.

## Выбрать следующий шаг

1. Сформулируйте один наблюдаемый вопрос: «почему объект скрыт», «какие данные нужны маршруту» или «где задаётся приоритет действия».
2. Найдите этот вопрос в таблице и откройте соответствующую страницу.
3. Проверьте её исходные условия: нужна ли игровая среда BankaBot, геодата либо проект с его скриптовыми зависимостями. Общие руководства EyeAuras не добавляют эти компоненты автоматически.

| Вопрос | Страница |
| --- | --- |
| Что за поставка нужна и с чего начиналась подготовка | [С чего начать](/ru/BankaBot/getting-started) |
| Где описать выбор цели, действие и приоритет | [Деревья поведения](/ru/BankaBot/behavior-trees) |
| Почему объект показан, скрыт или перекрашен | [Правила и OSD](/ru/BankaBot/rules) |
| Откуда взять данные о проходимости мира | [Геодата](/ru/BankaBot/geodata) |
| Как разделить логику на части и определить зависимости кода | [Скрипты](/ru/BankaBot/scripting/getting-started) |

Например, для вопроса «объект есть, но не выделен нужным цветом» сначала нужны правила и приоритет отображения. Для «цель выбрана, но путь проходит через препятствие» нужен совместимый набор геодаты; смена цвета объекта задачу навигации не решит.

## Что искать в документации своей поставки

| Тема | Какие сведения нужны |
| --- | --- |
| Профили | Что сохраняется, какие зависимости входят в экспорт и как импортировать в нужную версию |
| Маршруты и споты | Точки пути, границы рабочей зоны и ручная настройка движения |
| Радар как отдельный режим | Источник объектов и способ показа без предположения, что включён сценарий управления персонажем |
| AI Code Assistant | Доступ к контексту проекта, используемые типы и проверка предложенного кода |
| Совместимость | Конкретные клиент, сервер, защита и версия BankaBot, а не только название игры |
| Prerequisites | Значение каждого требования подготовки и порядок его выполнения |

Для этих тем нельзя подставлять интерфейс другого продукта по похожему названию. Если вы изучаете сам EyeAuras, а не BankaBot, начинайте с [аур](/ru/home), [первого дерева](/ru/behavior-trees/gettings-started) или [C# Script](/ru/scripting/getting-started). Это отдельный путь знакомства с общей платформой.
