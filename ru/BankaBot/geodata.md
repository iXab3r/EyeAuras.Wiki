# Геодата — выбрать данные для навигации BankaBot

Если цель видна, но до неё нужно обойти стену или перепад высоты, одного положения цели недостаточно. Геодата описывает проходимость игрового мира: где можно двигаться и как связаны участки поверхности. В историческом описании BankaBot она поставлялась отдельно от программы.

## Выбрать подходящий источник

Нужны совместимая поставка BankaBot, известные клиент и хроники, а также набор геодаты для этого окружения. Это подготовленные данные мира, а не результат OCR или поиска изображения в EyeAuras.

1. Сопоставьте окружение своей конфигурации с описанием набора. Данные от другого мира или хроник нельзя считать подходящими по одному совпадению названия игры.
2. Определите, что у вас уже есть: готовый источник, папка набора или его архив. В прежнем руководстве были предусмотрены три способа подключения из таблицы.
3. В разделе геодаты соответствующей поставки выберите этот способ и источник по её инструкции. Для папки или архива важны поддерживаемая структура и формат, а не произвольное расширение файла.
4. Проверьте, какой набор выбран для навигации, прежде чем настраивать маршрут и рабочую зону. При нелогичном пути сначала сверяйте мир и геодату, затем логику движения.

| Способ из описания BankaBot | Откуда берутся данные |
| --- | --- |
| Скачать подготовленный набор из программы | Из источника, предусмотренного поставкой BankaBot |
| Импортировать папку | Из уже имеющегося у вас совместимого набора с нужной структурой |
| Импортировать архив | Из совместимого набора в поддерживаемой упаковке |

Здесь не задаётся универсальное имя каталога или формат для всех версий. Конкретный загрузчик, состав файлов и порядок выбора относятся к поставке BankaBot; копирование этих действий в обычный EyeAuras не создаёт навигационный модуль.

## Что должно измениться после подключения

У навигации появляется источник сведений о проходимости для построения путей и перемещения между точками. Для описанной конфигурации эти данные также использовались при работе с маршрутами, миникартой и ограничением зоны фарма. Набор можно обновлять отдельно от самой программы.

| Задача | Роль геодаты |
| --- | --- |
| Обойти препятствие | Даёт основу для выбора проходимого пути вместо прямой линии |
| Учесть высоту и форму локации | Описывает поверхность мира, с которой сопоставляется маршрут |
| Проверить странный маршрут | Помогает отделить неподходящий набор мира от ошибки логики движения |
| Получить HP, MP или список игроков | Этого геодата не даёт: такие данные относятся к игровой среде BankaBot |

Выбранный источник — результат этапа подготовки, а не гарантия, что любой путь будет построен верно. Геодата, текущие объекты мира и [дерево поведения](/ru/BankaBot/behavior-trees) решают разные части задачи. Начальный состав поставки разобран в [подготовке BankaBot](/ru/BankaBot/getting-started).
