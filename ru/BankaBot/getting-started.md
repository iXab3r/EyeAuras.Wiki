# BankaBot — подготовить свою поставку к настройке

Прежде чем менять профиль или запускать поведение персонажа, отделите сам BankaBot от EyeAuras, внутри которого он работает. Здесь описана специальная поставка для Lineage 2 из руководства марта 2026 года. Это не универсальная настройка любого клиента через обычные триггеры EyeAuras.

## Что нужно иметь перед настройкой

| Что подготовить | Для чего это нужно |
| --- | --- |
| Поставка BankaBot и описание её версии | Определяют доступные окна настроек, игровые данные и поддерживаемое окружение |
| Предусмотренный этой поставкой доступ | В прежнем описании был вход по ключу BankaBot без отдельного аккаунта либо через учётную запись EyeAuras. Способ входа не определяет автоматически состав доступных компонентов |
| Поддерживаемый сервер и клиент Lineage 2 | В описании прямо оговаривалось, что поддерживаются не все серверы, часть исключена |
| Одно однозначно выбранное окно игры | Описанный режим действий требовал активного окна; работа с несколькими окнами одновременно не поддерживалась |
| Данные для выбранной задачи | Например, совместимая геодата для маршрутов; само наличие бота не означает наличие нужного набора мира |

Сведения о получении поставки и её доступе относились к [странице BankaBot, указанной в руководстве](https://banka.gg/product/tprwcjh69vjh2kh/). [Регистрация EyeAuras](https://eyeauras.net/register) была одним из вариантов подготовки учётной записи; она не заменяет сведения о доступе к конкретному BankaBot. Способ входа, срок ключа и доступные компоненты сверяйте с условиями своей поставки.

## Порядок подготовки в описанной поставке

1. Сопоставьте свою копию BankaBot с её сопровождающим описанием: версия, поддерживаемый клиент и сервер. Не подменяйте это наличием обычного EyeAuras.
2. После предусмотренного поставкой входа откройте настройки. В прежнем руководстве первым шагом был раздел `Prerequisites`: он показывал необходимые условия подготовки.
3. Разберите требования именно своей версии и устраните недостающую подготовку по её инструкции. Не угадывайте, что проверяет пункт, по одному названию.
4. Выберите своё окно игры и проверьте соответствие клиента. Затем выберите одну небольшую задачу: отображение объектов, готовый профиль либо простую ветку поведения.
5. Для навигации сначала подготовьте [геодату](/ru/BankaBot/geodata). Для условий и действий изучите [дерево поведения](/ru/BankaBot/behavior-trees), а для оформления объектов — [правила](/ru/BankaBot/rules).

Результат подготовки — известная вам версия BankaBot, понятный набор её требований и один выбранный адресат. Это ещё не результат фарма или проверка маршрута: их оценивают отдельно в конкретной конфигурации.

## Какие возможности были описаны

| Возможность | Что за ней стоит |
| --- | --- |
| Деревья поведения | Выбор целей, проверки расстояния, использование умений и приоритеты из доступных BankaBot данных |
| C# и NuGet | Скрипты и более крупные проекты в среде EyeAuras, дополненные игровым контекстом BankaBot |
| OSD | Метки объектов, подсветка и маршруты поверх изображения игры |
| AI Code Assistant | Помощь с кодом и документацией; результат всё равно требует сверки с API конкретной поставки |
| Пользовательский режим без драйверов | Характеристика описанной поставки; она не является гарантией незаметности или совместимости с любой защитой |

В прежнем описании упоминались Active Anticheat и Smart Guard. Это сведения о той конфигурации, а не актуальная таблица поддержки всех версий защит и серверов. Фоновая отправка действий и одновременная работа с несколькими окнами в ней не предоставлялись; предложение будущей функции не делает её доступной настройкой.

Сам BankaBot описывался как программа-скрипт внутри EyeAuras. Отсюда и важная граница: обычный C# Script не получает игровые объекты только потому, что использует тот же язык. Подробнее — [скрипты BankaBot](/ru/BankaBot/scripting/getting-started) и [темы раздела](/ru/BankaBot/documentation-topics).
