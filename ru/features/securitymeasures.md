# Выбрать запуск через подготовленную копию

**Security measures** меняет запуск самого EyeAuras: программа готовит отдельную копию в каталоге со случайным именем внутри LocalAppData, меняет имя исполняемого файла, обрабатывает копию и запускает её вместо исходного процесса. Исходный процесс после передачи запуска завершается. Режим позволяет запускать программу из подготовленного расположения с другим именем, сохраняя исходную установку для следующих запусков.

Подготовка может копировать файлы программы или использовать отдельное имя для исполняемого файла; пользовательские ауры при этом не превращаются в новый опубликованный Pack. Режим не гарантирует незаметность или совместимость с защитой любой другой программы.

Для настройки возьмите собственную работающую конфигурацию и сохраните важные ауры [локальным экспортом](/ru/features/export-import). Изменение применяется при запуске, поэтому сначала завершите текущую работу.

1. Откройте настройки EyeAuras и найдите **Security measures**.
2. Включите флажок и нажмите **Save**. При переходе из выключенного состояния приложение предложит перезапуск; подтвердите его, когда будете готовы.
3. Дождитесь подготовки копии и нового окна EyeAuras. Проверьте свой профиль и знакомые ауры. Появление нового процесса после завершения исходного соответствует передаче запуска, а не созданию независимого пользовательского набора. Время подготовки зависит от поставки и файлов программы.
4. Если ваш сценарий требует открыть EyeAuras раньше целевого приложения, сначала завершите этот перезапуск, затем открывайте цель.
5. Для возврата снимите флажок, нажмите **Save** и выполните следующий штатный запуск. Уже запущенная подготовленная копия и явный параметр запуска имеют приоритет над сохранённым флажком: проверяйте, какую копию запускаете. Смена флажка не переключает работающий процесс на месте.

## Выбрать механизм под задачу

| Механизм | Что меняется |
| --- | --- |
| Security measures | Подготовка и передача запуска отдельной копии EyeAuras. |
| Упаковка приложения и модулей | Состав поставки и загрузка частей программы; это отдельный уровень от выбора режима запуска. |
| Private Content у папки | Просмотр и редактирование через интерфейс; см. [права доступа](/ru/features/permission-model). |
| Binaries Only и Script Protection Mode | Распространяемый текст и обработка бинарного кода; см. [защиту скриптов](/ru/features/script-protection). |
| Сублицензия | Доступ к конкретному продукту автора. |
| Подтверждение запуска чужой логики | Ваше решение доверять конкретному действию или набору. Оно не включает Security measures и не выдаёт лицензию. |

<details>
<summary>Настройка для переносимого Pack</summary>

В **Pack Options** есть переопределение **Security Measures**:

| Значение | Что задаёт автор комплекта |
| --- | --- |
| Not set | Не переопределять значение исходной конфигурации. |
| Enable | Включить режим подготовленной копии. |
| Disable | Отключить его для комплекта. |

Проверьте готовый комплект отдельным запуском перед распространением. О его составе и подготовке — в [статье о Pack](/ru/features/packs); [ранний анонс упаковки](https://wiki.eyeauras.net/en/changelogs/6736) относится к истории этой возможности.

</details>

Выбор захвата, программного или аппаратного ввода, размещение частей системы на разных компьютерах и добавление внешних библиотек остаются отдельными решениями. Проверяйте их требования и фактический результат для своего сценария.
