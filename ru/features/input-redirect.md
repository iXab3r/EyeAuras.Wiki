# Отличить перенаправление ручного ввода от действия ауры

**Input Redirect** назывался режим, который перехватывал ручные события клавиатуры и мыши и повторял их выбранным механизмом ввода. Это отличалось от команды ауры: в ней EyeAuras отправляет заранее настроенное действие при выполнении условия.

Страница относится к прежнему режиму. Его старые переключатели, выбор `Input Redirect Simulator` и элементы нижней панели не являются действующим путём настройки в нынешнем интерфейсе. Наличие старого названия лицензии также не добавляет эти элементы в установленную сборку.

## Выбрать подходящий нынешний путь

1. Сформулируйте, что должно стать источником команды: определённое условие ауры или каждое ваше физическое нажатие.
2. Для одной команды по условию откройте [Send Sequence](/ru/actions/sendinput/send-sequence). Там настраиваются сама последовательность, **Target Window** и **Input Simulator**. Начните с своего отдельного тестового окна и только одного действия.
3. Если нужен текст, используйте [отправку текста](/ru/actions/sendinput/send-text), а для собственного сочетания как условия — [Hotkey Is Active](/ru/triggers/hotkey-is-active). Триггер сочетания не означает автоматического повторения всех событий клавиатуры.
4. Если задача именно в непрерывном перенаправлении физического ввода, сначала нужна поставка с документированным режимом и его настройками. Обычный выбор способа ввода в действии такую функцию не включает.

Результат выбора — понятный источник события и поддерживаемый механизм команды. Это не замена старого перенаправления универсальным глобальным перехватчиком.

| Историческое имя | К чему относилось |
|---|---|
| `Input Redirect Simulator` | Механизм повторной отправки перехваченных событий. |
| `Input Redirect Timeout` | Временной параметр прежней обработки событий; его нельзя переносить в задержку Send Sequence по одному названию. |
| `Input Grace Period` | Отдельный временной параметр прежнего режима после отпускания клавиши. |
| `Input Redirect Ignored Modifiers` | Фильтр модификаторов при перехвате, а не общий список модификаторов команды ауры. |
| `Input Redirect Logging` | Журнал прежнего перенаправления; не переключатель логирования всех действий приложения. |

У этой архивной схемы нельзя предполагать нынешний порядок подавления, пересылки `Down`/`Up`, выбора адресата и освобождения удерживаемых клавиш после остановки. В [обычном вводе](/ru/actions/sendinput/options) действуют контракты выбранного механизма и действия. Для сценария удалённого рабочего стола отдельно проверяются сессия и доступность окна.
