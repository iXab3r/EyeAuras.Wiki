# Key Press — перенести прежнюю настройку на текущий узел

Если вы пришли сюда из старого примера с `Key Press`, используйте текущий шаблон с тем же именем. Отдельного второго узла для этого написания страницы выбирать не нужно. Полное руководство по событиям, удержанию и сочетаниям находится на странице [Key Press](/ru/behavior-trees/nodes/KeyPress).

## Настроить адресата и проверить одну клавишу

Подготовьте своё отдельное окно локального текстового редактора с одной строкой черновика. Поставьте каретку в середину строки. Для проверки выберем Home: перемещение каретки видно без буфера обмена и отправки текста.

1. Поместите дерево в отдельную папку. В её `Triggers/Actions/Overlays Defaults` включите `Target Window` и выберите окно черновика. Через `show more...` включите `Input Simulator → Windows Input`.
2. В дереве оставьте `Activation → Is Loaded`, `Execution → When Activated → Do nothing`. В `Settings` проверьте, что нет другой локальной цели или механизма. Значения могут наследоваться от папки либо задаваться локально у дерева; подробнее — [свойства по умолчанию](/ru/features/default-properties).
3. Добавьте текущий `Key Press` через `Add new Node` и соедините со входом. Задайте `General → Keys = Home`, `Delay = 30 ms`, `Input → Press and release`.
4. В `Window` узла проверьте точное окно черновика, в `Simulator` — Windows Input. Эти поля показывают результат наследования, а не отдельный ручной выбор внутри узла.
5. Выполните один `Tick BT Once`. Windows Input активирует выбранный редактор, каретка должна перейти в начало строки, узел — завершиться с Success. Если проверяете существующую схему, сначала воспроизведите только этот один шаг в своей копии.

Для текущих подписей используйте соответствие ниже:

| Прежняя настройка или задача | Текущий путь |
| --- | --- |
| Клавиша или сочетание | Key Press → General → Keys |
| Key Press Delay | General → Delay, с постоянным значением или случайным диапазоном |
| Input Type | General → Input: Press and release, Press and hold либо Release |
| Окно и симулятор из Folder Properties | Значения по умолчанию папки; локальные Settings дерева могут их переопределить. Проверяйте итоговые Window / Simulator в узле |
| Длинная последовательность | Несколько Key Press в BT Sequence либо Run Aura с настроенным действием Send Sequence |

Последний вариант сохраняет возможность использовать готовый [Send Sequence](/ru/actions/sendinput/send-sequence) через [Run Aura](/ru/behavior-trees/nodes/execute-aura): настройте окно и ввод у **исходного действия**, они не подставляются в него автоматически из дерева. Не рассчитывайте на автоматическое преобразование старой сложной конфигурации только из-за совпадения имени.

Выбранный Target Window не гарантирует фоновую работу. В опыте используется Windows Input с активацией собственного окна; для других механизмов действуют их ограничения. Если в старой схеме использовалось удержание, перенесите и отдельный Release: остановка между Down и Up сама по себе его не заменяет.
