# Selector — выбрать действие по приоритету

Selector перебирает детей по порядку и останавливается на первом, который выполнился успешно. Типичная задача: применить умение, если оно готово, а иначе — ударить обычной атакой.

Сначала проверьте порядок на [Fixed Status](/ru/behavior-trees/nodes/fixed-status) вместо настоящих проверок и действий. Как запустить загруженное дерево вручную — в [первом примере](/ru/behavior-trees/gettings-started).

## Соберите два варианта атаки

Для примера нужны три уже настроенные ауры:

| Аура | Что делает |
| --- | --- |
| Умение готово | Активна, когда умение доступно. Например, проверяет его иконку. |
| Применить умение | Нажимает нужную клавишу. |
| Обычная атака | Выполняет базовую атаку. |

Добавьте в дерево Selector. Первый ребёнок — Sequence из проверки Aura Is Active и действия Run Aura, второй — ещё один Run Aura:

```text
Selector
├─ Sequence
│  ├─ Aura Is Active → «Умение готово»
│  └─ Run Aura → «Применить умение»
└─ Run Aura → «Обычная атака»
```

В Aura Is Active выберите ауру «Умение готово» и проверку её активного состояния. В каждом Run Aura выберите свою ауру с действием.

[Sequence](/ru/behavior-trees/nodes/sequence) склеивает проверку и применение умения в один вариант. Без неё проверка была бы отдельным ребёнком Selector, и её успех остановил бы выбор ещё до атаки.

## Проверьте результат

Когда «Умение готово» активна, дерево проходит первую ветку и обычную атаку не выполняет. Когда условие не выполнено, Sequence возвращает Failure, и Selector переходит ко второму варианту.

## Как Selector выбирает дальше

| Результат ребёнка | Поведение Selector |
| --- | --- |
| Failure | Пробует следующего ребёнка. Если вариантов больше нет, возвращает Failure. |
| Success | Возвращает Success. Остальные варианты в этом обходе пропускает. |
| Running | Возвращает Running и запоминает этого ребёнка. При следующем обходе продолжает с него. |

Пока первая ветка выполняется, Selector не переходит к обычной атаке. Более ранние варианты он в это время тоже не перепроверяет. Учтите это, если хотите добавить срочную ветку с более высоким приоритетом.

Когда выбор завершён, следующий обход снова начинается с первого ребёнка. Приоритет задаётся порядком веток, отдельного параметра «приоритет» нет.
