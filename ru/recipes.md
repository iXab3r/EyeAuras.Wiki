# Выбрать задачу для своего набора

Рецепты соединяют несколько возможностей EyeAuras для одной конкретной задачи. Выберите нужный результат, подготовьте указанное окно или изображение и пройдите настройку целиком. Отдельные руководства объясняют подробные параметры и варианты.

Начните с [базовых рецептов](/ru/recipes/basic): для них не нужно программирование. Напоминанию по переднему окну достаточно вашего окна и введённого текста; проверке изображения нужен источник текущих пикселей. Для звукового рецепта нужен доступный аудиовыход.

| Что нужно получить | Рецепт |
| --- | --- |
| Держать памятку подготовки рядом с заметками, не принимая её за статус записи | [Памятка по переднему окну](/ru/recipes/basic/recording-reminder) |
| Различать появление просмотрщика и закрытие его окна | [Отдельные сигналы открытия и закрытия](/ru/recipes/basic/viewer-open-close-cues) |
| Проверять цветную панель только по запросу | [Проверка цвета при удержании клавиши](/ru/recipes/basic/hold-to-inspect) |
| Услышать один сигнал о настоящем значке в своём приложении | [Сигнал о значке готовности](/ru/recipes/basic/ready-icon-alert) |
| Заметить предупреждающий цвет источника, работая в другом окне | [Цветовой индикатор без фокуса](/ru/recipes/basic/off-focus-color-indicator) |
| Сверяться со своей статичной схемой или памяткой | [Справочная карточка](/ru/recipes/basic/reference-card) |
| Держать в поле зрения меняющийся участок окна | [Живая область состояния](/ru/recipes/basic/live-status-crop) |
| Разрешить клавишу уведомления только в одном приложении | [Клавиша уведомления своего приложения](/ru/recipes/basic/application-only-shortcut) |

Выбирайте памятку или статичную карточку, когда заранее знаете, что хотите показать. Проверка изображения нужна, когда условие должны дать сами захваченные пиксели, а Replica — когда достаточно живой копии. В рецептах указаны переходы, при которых ожидается результат, и влияющие на него настройки. Выбор окна-источника сам по себе не разрешает и не отправляет ввод.
