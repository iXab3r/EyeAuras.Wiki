# Подготовить набор Scryde для Lineage 2

Для low-rate серверов со старыми хрониками опубликован отдельный набор **Scryde autofarm Behavior Tree**. Начните с его описания и состава: название раздела Lineage 2 не означает, что EyeAuras содержит встроенные сведения о здоровье, целях или правилах любого сервера.

[Публикация автора](https://eu.eyeauras.net/share/S202403150219539BfeOJ0eRl1q) — редакция **5**, подготовленная в **EyeAuras 1.4.7520.0** и выпущенная **31 января 2025 года**. Это версия набора, а не обещание совместимости с любым нынешним клиентом Lineage 2. Нужны подходящий клиент, собственная конфигурация его клавиш и версия EyeAuras, с которой работает этот набор.

## Получить и проверить состав

1. Скачайте EyeAuras с [официальной страницы](https://eu.eyeauras.net/download). Для доступа к своему аккаунту используйте [вход на сайте](https://eu.eyeauras.net/login); необходимость лицензии определяется используемыми функциями и доступом к набору, а не одним названием игры.
2. Откройте публикацию и сопоставьте имя **Scryde autofarm Behavior Tree**, автора **linqse** и редакцию. Прочитайте описание до импорта.
3. В EyeAuras нажмите **Import**, вставьте ссылку в **Source** и нажмите **Download**. На **Preview** просмотрите дерево и зависимости. Если у вас уже есть этот набор, сначала разберите конфликты по [руководству импорта](/ru/features/export-import), чтобы не заменить свою рабочую копию случайно.
4. До включения просмотрите доступные настройки окон, сочетания клавиш и способы ввода. Там, где используется **Target Window**, выберите своё окно клиента. У узлов поиска проверьте предпросмотр пикселей по [руководству захвата](/ru/triggers/images/imagecapturetriggers): имя окна само по себе не подтверждает правильную область.
5. Сопоставьте меню и клавиши набора с таблицей ниже. Только после проверки адресата и действий переходите к запуску в подходящем окружении. У другой редакции настройки могут отличаться.

Результат подготовки — выбранная версия набора с понятным составом и проверенным окном. Импорт конфигурации ещё не подтверждает её работу на вашем сервере и не подставляет игровые данные в EyeAuras.

| Пункт из описания редакции 5 | Назначение |
|---|---|
| `PageUp` | Стандартная клавиша меню набора. |
| `Alt+Shift+Z` | Переключение автоохоты по описанию автора; не нажимайте до проверки настроек. |
| `Combat` | Спойл, повторение клавиш, вариант для суммонера. |
| `Heal` | Лечение персонажа и суммона, воскрешение суммона, две группы бафов. |
| `Target Selector` | Следующая цель и пропуск цели через заданное время. |
| `Alerts` | Реакции на смерть и снятие бафа, действие возвращения в город. |

Следование по миникарте, игнорирование цели и возвращение в центр в этой публикации отмечены как **планируемые**. Их нельзя считать готовыми функциями только по названиям разделов. Источники условий определяются конкретными узлами и скриптами набора; универсального игрового API здесь не подразумевается.

## Выбрать механизм ввода

В параметрах ввода EyeAuras доступны разные способы доставки. [Windows Input](/ru/actions/sendinput/options) и `Windows Message API` имеют разные требования к фокусу и адресату: второй работает только с приложениями, принимающими такие сообщения. Ни один из них не обещает работу в любом свёрнутом окне.

[TetherScript Driver](/ru/actions/sendinput/tetherscript) требует заранее установленного совместимого виртуального HID-драйвера. Выбор по названию античита не является проверкой совместимости или разрешением со стороны сервера.

<details>
<summary>Подготовка старых клиентов и драйвера</summary>

В старом руководстве использовался [HVDK Standard 2.1](https://s3.eyeauras.net/media/2024/10/HVDK%20Standard%202.1.exe). Его наличие по ссылке не означает, что он подходит вашей версии Windows; текущий путь подготовки смотрите в статье TetherScript. Не запускайте удаление драйверов по пути от другой установки ControlMyJoystick.

Если после установки виртуального устройства камера вращается сама, в старых клиентах рекомендовалось открыть `Settings → Configuration` и отключить `Enable Controller`. Этот совет относится к клиентам с таким параметром; он не заменяет проверку остальных устройств ввода.
