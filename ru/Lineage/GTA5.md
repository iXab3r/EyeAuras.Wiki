# Проверить задержки фоновых приложений при GTA 5

Бывает, что при открытой GTA 5 браузер или EyeAuras начинают заметно тормозить. Такое замечали с AltV и RageMP, но причина не обязательно в клиенте. Ниже — две настройки Windows, которые стоит проверить.

Нужна Windows с этими настройками и задержка, которую легко повторить. Например, одна и та же страница в браузере перестаёт плавно прокручиваться только во время игры. Сначала запишите, как стоят переключатели сейчас. Меняйте по одному параметру за раз.

## Сравнить два состояния

1. Вызовите задержку как обычно и запомните, как она выглядит. Не меняйте одновременно частоту захвата EyeAuras и настройки Windows, иначе не поймёте, что именно помогло.
2. Откройте **Settings → Gaming → Game Mode** и переведите **Game Mode** в **Off**. Повторите то же самое при открытой игре. Разницы нет — верните как было.
3. Отдельная проверка для Windows 11: откройте **Settings → System → Display → Graphics**. В **Custom options for apps** выберите исполняемый файл игры, откройте **Options** и отключите для него **Optimizations for windowed games**. Нажмите **Save** и перезапустите игру. Если включён Auto HDR, возможно, сначала придётся отключить его.
4. Повторите проверку. Оставляйте изменение, только если стало заметно лучше. Если нет — верните записанные значения и перезапустите игру.

Оптимизация оконных игр работает для совместимых приложений на DirectX 10/11 в оконном режиме и в режиме без рамки. [Microsoft описывает её назначение и настройку отдельно](https://support.microsoft.com/en-us/windows/hardware/display-graphics/optimizations-for-windowed-games-in-windows-11).

Если тормозит только аура с поиском по изображению, это другой, более узкий вопрос. Настройки Windows пока не трогайте. Откройте [статистику захвата](/ru/triggers/images/imagecapturetriggers) и сравните время захвата, эффектов и обработки с заданной частотой.

В русской Windows названия переведены.

![Game Mode в настройках Windows](https://s3.eyeauras.net/media/wiki/Lineage/GTA5/Discord_tRNKShE2GYG74pgRIecTtoNII.png)

| Параметр | Область изменения |
|---|---|
| `Game Mode` | Общий игровой режим Windows. Проверяйте отдельно от графической настройки приложения. |
| `Optimizations for windowed games` | В Windows 11 меняется для конкретной игры. После изменения перезапустите её. |
| Исходное положение | Запишите его, чтобы вернуть настройку, если проверка не помогла. |

На старом снимке оптимизация оконных игр находится в **Default graphics settings** и меняется сразу для всех приложений.
