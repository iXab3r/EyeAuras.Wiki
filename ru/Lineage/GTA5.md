# Проверить задержки фоновых приложений при GTA 5

Если при открытой GTA 5 браузер или EyeAuras начинают отвечать заметно медленнее, сравните поведение с двумя настройками Windows. Такая проблема описывалась для окружений AltV и RageMP, но по одному названию клиента нельзя установить её причину. Отключение настроек ниже — проверка на своём компьютере, а не обязательная оптимизация для всех.

Нужна Windows с соответствующими параметрами и повторяемое наблюдение: например, одна и та же открытая страница браузера перестаёт плавно прокручиваться только во время игры. До изменений запишите исходные положения переключателей. Меняйте один параметр за раз.

## Сравнить два состояния

1. Воспроизведите задержку обычным способом и запомните её проявление. Не меняйте одновременно частоту захвата EyeAuras и настройки Windows: иначе будет непонятно, что повлияло на результат.
2. Откройте **Settings → Gaming → Game Mode** и переведите **Game Mode** в **Off**. Снова сравните тот же фоновой сценарий при открытой игре. Если разницы нет, верните исходное значение.
3. Для отдельной проверки в Windows 11 откройте **Settings → System → Display → Graphics**. В **Custom options for apps** выберите исполняемый файл игры, откройте **Options** и отключите **Optimizations for windowed games** для него. Нажмите **Save** и перезапустите игру. При включённом Auto HDR отключение этой оптимизации может требовать сначала отключить Auto HDR.
4. Повторите то же наблюдение. Оставляйте изменение только при понятном полезном результате; если его нет, восстановите записанные значения и перезапустите игру после изменения графических параметров.

Результат этой проверки — сравнение отзывчивости в одном сценарии. Оно не доказывает универсального роста FPS или исправления всех задержек аур. Оптимизация оконных игр относится к совместимым DirectX 10/11 приложениям в оконном режиме и режиме без рамки; [Microsoft описывает её назначение и настройку отдельно](https://support.microsoft.com/en-us/windows/hardware/display-graphics/optimizations-for-windowed-games-in-windows-11).

На снимке 2024 года показан переключатель `Game Mode`. В русской Windows названия переведены.

![Game Mode в настройках Windows](http://files.eyesquad.net/screenshots/11-09-2024/Discord_tRNKShE2GYG74pgRIecTtoNII.png)

| Параметр | Область изменения |
|---|---|
| `Game Mode` | Общий игровой режим Windows; проверяется отдельно от графической настройки приложения. |
| `Optimizations for windowed games` | В Windows 11 можно менять для конкретной игры; после изменения перезапустите её. |
| Исходное положение | Позволяет вернуть настройку, если опыт не помог. |

На втором старом снимке оптимизация оконных игр находится в **Default graphics settings** и меняется глобально. Современный путь для конкретного приложения выше позволяет начать с одной игры, не меняя этот параметр для всех.
