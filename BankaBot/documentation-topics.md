# Choose a BankaBot guide

Find the guide that answers your next question without mixing display settings, behavior logic and navigation data.

These pages cover the historically documented BankaBot edition. Keep the instructions for your matching distribution available for concrete controls, data formats and supported clients.

1. Write down one observable goal: highlight an object, understand a behavior branch, or prepare data for movement.
2. Choose the corresponding guide below. Identify the data it needs before configuring a reaction.
3. Return to [Getting started](/en/BankaBot/getting-started) if the build, client or required data is still unclear.

| Your question | Guide |
| --- | --- |
| Which edition, client, access method and window do I need? | [Getting started](/en/BankaBot/getting-started) |
| How do target checks and actions form a behavior? | [Behavior trees](/en/BankaBot/behavior-trees) |
| When should custom events, timers or calculations become C# code? | [Scripting](/en/BankaBot/scripting/getting-started) |
| Why is an object hidden or highlighted? | [Rules](/en/BankaBot/rules) |
| Why does a proposed route cross an obstacle? | [Geodata](/en/BankaBot/geodata) |

For example, changing a marker's color belongs in rules. Correcting an obstacle dataset belongs in geodata. Neither operation defines which target a behavior may attack.

## Information to find in your edition's manual

The following subjects need concrete instructions for the particular BankaBot distribution. They are not additional procedures supplied by this index.

| Subject | Information you need |
| --- | --- |
| Profiles | Storage location, import/export format and how a profile is selected |
| Routes, spots and work areas | Waypoint or area format, manual preparation and movement requirements |
| Standalone radar | Entry point, available object data and display controls |
| AI assistant | Supported project context and how to check generated code against the actual API |
| Compatibility and limitations | Supported clients, servers, anti-cheat environments and window restrictions |
| Prerequisites | The meaning of each preparation check and how to satisfy it |

For platform concepts, use [EyeAuras documentation](/en/home), the [general behavior-tree introduction](/en/behavior-trees/gettings-started), or [C# scripting introduction](/en/scripting/getting-started). They explain EyeAuras; they do not supply missing BankaBot game interfaces.
