# Find the right place for help

If you do not know how to set up a feature, start with the guide. If you set it up and it works differently, write down your EyeAuras version and short steps that repeat the problem. With those you will get help faster.

1. A setup question: open [Home](/en/home) and pick the feature you need. For a shared pack, also read the author's description.
2. A question for the community: join the [EyeAuras Discord](http://discord.gg/cvR5ZUM).
3. A bug to sort out: [prepare a report](/en/report-a-problem) first. A saved archive stays with you until you send it to someone yourself.

| Channel | Purpose |
| --- | --- |
| [Official contacts page](https://eyeauras.net/contacts) | Links to the community, documentation and video guides |
| [Discord community](https://discord.gg/cvR5ZUM) | Setup questions, pack discussion and community help |
| [EyeAuras YouTube](https://www.youtube.com/%40eyeauras) | Feature overviews and setup on video |
| [iXab3r on Telegram](https://t.me/iXab3r) | Direct contact from the EyeAuras help page |
| mail.eyeauras@gmail.com | Fallback e-mail address from the help page |

In your message, include the feature or pack name, application version, what you did, what happened and what you expected. If you already sent a report with **Send**, add its ID.
