# Find the right place for help

Choose a guide for setup, community discussion for a configuration question, or a diagnostic report when existing behavior differs from what you expected.

1. Start at [Home](/en/home) to find the relevant function. For a shared pack, also read its author's requirements.
2. Use the [EyeAuras Discord invitation](http://discord.gg/cvR5ZUM) for community troubleshooting and pack questions. The invitation opens the community; the old `Xab3r#3780` discriminator is not needed to use it.
3. For a reproducible problem, [prepare a report](/en/report-a-problem) before contacting support. Saving an archive keeps it local until you choose to send it.

| Channel | Purpose |
| --- | --- |
| [Official contacts page](https://eyeauras.net/contacts) | Current first-party links to the community, documentation and videos |
| [Discord community](https://discord.gg/cvR5ZUM) | Configuration help and discussion |
| [EyeAuras YouTube](https://www.youtube.com/%40eyeauras) | Walkthroughs, release overviews and feature demonstrations |
| [iXab3r on Telegram](https://t.me/iXab3r) | Direct contact listed in the EyeAuras help page |
| mail.eyeauras@gmail.com | Fallback e-mail address listed in the help page |

Include the feature or pack name, application version, steps, actual result and expected result. If you already used **Send**, include the report ID. Opening a chat, reading a guide or saving a file does not submit a report.
