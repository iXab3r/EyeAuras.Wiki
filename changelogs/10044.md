# Alpha - 1.9.10044 [RU](/ru/changelogs/10044)/[EN](/en/changelogs/10044)

A patch with fixes for Behavior Tree, EyePad and macro sharing.

Startup can occasionally take a long time. I'm still investigating the cause.

## Fixes / improvements

* **[Behavior Tree]** Timeout and Interrupter now cancel an action they are waiting for if it supports cancellation, then wait for it to finish.
* **[Behavior Tree]** Fixed restarting after unloading a tree and handing a shared SubTree between calling trees. The previous execution finishes before the next one starts.
* **[Macros]** Fixed finding linked macros and trees during export, and the filename when saving a pack without auras. Linked macro names now update after renaming.
* **[EyePad]** Fixed text synchronization during fast typing and read-only protection when opening tabs. Completion suggestions can be applied in editable tabs.
* **[EyePad]** Fixed restoring open files at startup and tab context menus.
* **[Scripts]** Fixed importing C# solutions with spaces in project names and paths. Added support for recognizing SDK-style projects.
* **[Windows]** File open and save dialogs now belong to the window that opened them. Fixed a blank page when using Reload before the initial page has loaded.
* **[Export]** After exporting a pack or C# project, Explorer opens through the Open in Explorer button instead of opening automatically.
* **[AI Assistant]** EyeAuras now uses its own version of Codex by default and downloads it when needed. Codex installations from editors and npm are no longer picked up automatically.
