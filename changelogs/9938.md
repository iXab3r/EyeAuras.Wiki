# Big Alpha - 1.9.9938 [RU](/ru/changelogs/9938)/[EN](/en/changelogs/9938)

Well, the moment I mentioned back in [1.9.9339](/en/changelogs/9339) is finally here - the old WPF shell is going away.

For the last few months, the WPF and Blazor interfaces have been living side by side. The Blazor UI has already been available for quite a while and was enabled by default for most users. Now the switch between the two is gone - the old shell is being retired for good, and all further changes will be made in the Blazor UI.

This is a very large update internally, so I am releasing it to **Alpha** first. There will probably be bugs :) Stable stays on `1.9.9774` for now.

## Overlays

Overlays were one of the last large pieces still tied to the old interface. In this build, their editors and core logic have finally moved to the Blazor UI.

`Replica Overlay` received most of the changes: region selection, resizing, and the editor itself were reworked. Replica now dims while selecting a region, and holding `Shift` preserves the aspect ratio while resizing.

The separate `Web UI Overlay` has been merged into `C# Overlay`. Existing configs should migrate automatically.

## Fixes / improvements

* **[Target Window]** Fixed an annoying bug where a value such as `PathOfExile.exe#2` could replace itself with a generated string containing the window address, process, and title.
* **[Bindings]** Restored Binding for `Target Window` in `ML Search`, `Image Search`, `Color Search`, `Text Search`, and other triggers, actions, and overlays that work with a window.
* **[UI]** Improved overlay region selection and resizing.
* **[UI]** Improved error and diagnostic information display.
