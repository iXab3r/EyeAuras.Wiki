# 1.9.9735 [RU](/ru/changelogs/9735)/[EN](/en/changelogs/9735)

Bugfixes.

## Fixes and improvements

* **[Crash]** EyeAuras no longer crashes on startup if it does not have enough permissions `#EA-1266`
* **[Scripting]** **Breaking change** - the tabs mechanism was moved from `EyeAuras.Blazor.Controls` to `PoeShared.Blazor.Controls` - update the namespace
* **[Scripting]** Fixed a UI freeze (deadlock) that could happen when loading large resources `#EA-1294`
* **[Scripting]** Improved `Embedded Resources` management in `Script Properties`: resource list, file operations, tree view display, list limits, and scenarios with references/NuGet.
* **[Scripting]** `EmbeddedResources` should now be easier to connect - added support for partial path matching (`/res/my.png` => `res/my.png` and `my.png` will find the resource)
* **[UI]** Small update to the `Send Sequence` editor - added previously missing elements for `MouseMove`
* **[UI]** Improved how errors are displayed in the interface `#EA-1295`
* **[UI]** Fixed an issue that prevented some windows from being dragged `#EA-1292`
* **[UI]** Small fix for NVIDIA timestamp handling in `Security measures` mode.
* **[AI]** AI now understands when items (auras/trees) have been unloaded `#EA-1265`
