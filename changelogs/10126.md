# Alpha - 1.10.10126 [RU](/ru/changelogs/10126)/[EN](/en/changelogs/10126)

An AI Assistant patch: new models, a cleaner chat look and clearer messages for sign-in problems.

## AI Assistant — Luna 6 by default

The built-in profiles have been updated: **Luna 6** in High, XHigh and Medium for OpenAI, and **Sonnet 5.5** and **Haiku 5.5** for Claude. **Luna 6 High** is now the default. The built-in Codex also uses Luna 6 by default.

**After the update, all saved AI profiles are removed and replaced with the new built-in ones.** Your other AI settings are kept. If you added a profile with your own key, server address or model, create it again in AI Settings.

## Fixes / improvements

* **[AI Assistant]** Cleaned up how chat replies look: code is no longer highlighted in pink, lists and paragraphs have proper spacing again, and text has better contrast.
* **[AI Assistant]** A missing microphone is no longer shown as a red error. The record button is now compact and only appears when a microphone is available. Connecting or disconnecting a microphone is now detected without a restart.
* **[AI Assistant]** If you are not signed in to your EyeAuras account or your session has expired, the chat now says so in a plain message and suggests signing in again or choosing another profile, instead of showing a technical error.
* **[AI Assistant]** Codex now starts even when you are not signed in; you'll be prompted to sign in when you send your first message.
* **[AI Assistant]** The assistant works better with the Wiki: code examples are no longer cut off midway, internal pages no longer show up in search results, and the assistant gets exact page links it can cite.
* **[AI Assistant]** Removed the extra **Start Session** button from the empty chat screen.
* **[Interface]** The import, export, rollback, pack and image editor windows now match the style of the **Settings** window. In the news panel, the version is shown on a single line with a status color and a tooltip, and the notes language is switched with flag buttons.

**Please report any issues!**
