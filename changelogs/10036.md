# Alpha - 1.9.10036 [RU](/ru/changelogs/10036)/[EN](/en/changelogs/10036)

A small patch with fixes for macros, EyePad and the interface.

## Fixes / improvements

* **[Authentication]** Improved authentication loading at startup.
* **[Macros]** Fixed branch selection in IfThenElse and exiting Repeat with Break. Also fixed loading profiles containing only macros.
* **[Behavior Tree]** Fixed focus being lost when renaming trees and macros, along with drop position indicators when dragging nodes.
* **[EyePad]** Fixed file renaming and the placement of code suggestions in the editor.
* **[Scripts]** Fixed selection of the main script project when loading a solution with multiple projects.
* **[Windows]** Fixed windows continuing to move after the mouse button was released.
