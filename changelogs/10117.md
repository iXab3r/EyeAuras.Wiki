# New release — 1.10.10117 [RU](/ru/changelogs/10117)/[EN](/en/changelogs/10117)

## Interface

I've removed the old shell and the switch between the old and new shells. There's no longer a need to maintain two interfaces or work around the old UI's limitations.

Merged **Web UI Overlay** into **C# Overlay**, with automatic migration of existing settings. Before updating, I recommend backing up your profile and checking your overlays after the switch.

## Sign in with Google, Twitch and Discord

Added sign-in through **Google**, **Twitch** and **Discord**. New users no longer need to register separately or create an EyeAuras password: choose a familiar service, confirm in the browser, and you're ready to go.

By default, sign-in is remembered between launches, including username and password sign-in. Available providers are the ones enabled on the website.

**To keep your existing account, licenses and history, first sign in on the website and link the provider in [Profile](https://eyeauras.net/my).**

Signing in with a license key is still available.

[More about signing in and linking accounts…](https://wiki.eyeauras.net/en/features/external-providers)

![Google, Discord and Twitch sign-in in EyeAuras](https://wiki.eyeauras.net/assets/releases/1.10/login-providers.png)

## Behavior trees and macros

**Timeout** and **Interrupter** now cancel an action they are waiting for if it supports cancellation, then wait for it to finish. When a shared **SubTree** is handed between calling trees, the previous execution also finishes before the next one starts.

In macros, fixed branch selection in **IfThenElse**, leaving **Repeat** through **Break**, and loading profiles that contain only macros.

Fixed finding linked trees and macros during export, updating their names after renaming, and the filename when exporting a pack without auras.

The node editor can now be expanded or opened in a separate window. Restored screen region selection in CV node editors, and fixed lost focus when renaming and the node insertion indicator.

![Expanded image search node editor](https://wiki.eyeauras.net/assets/releases/1.10/bt-expanded-editor.png)

## Mouse movement — ML Human Move

**ML Human Move** and **ML Human Move Fast** are now available in the **Send Input** smoothing settings. A trained model builds the mouse trajectory and chooses how long the movement takes; Fast is the quicker option. The model is included with the app.

![ML Human Move and ML Human Move Fast in folder properties](https://wiki.eyeauras.net/assets/releases/1.10/ml-human-move.png)

*Smoothing options in folder properties.*

## AI Assistant — its own version of Codex

By default, EyeAuras now chooses its own version of [Codex](https://wiki.eyeauras.net/en/features/ai-codex-coding-assistant) and downloads it when needed.

Codex installations from editors and npm are no longer picked up automatically.

## EyePad — files and folders

[EyePad](https://wiki.eyeauras.net/en/features/eyepad) now has **Explorer** — a working folder tree beside the editor. You can open, create, rename and delete files and folders.

In [Live Import](https://wiki.eyeauras.net/en/scripting/ide-integration), fixed loading solutions with multiple projects, spaces in names and paths, and recognizing SDK-style projects.

In the editor, fixed text synchronization during fast typing, file renaming, suggestion placement, tab menus, and restoring open files at startup.

Read-only tabs support highlighting and suggestions; completion can be applied in editable tabs.

## Fixes / improvements

* **[Mini-apps]** Fixed a hang when starting compiled mini-apps. The splash screen now closes when the mini-app is ready.
* **[Pack protection]** Fixed protecting packs with compiled scripts already saved in storage.
* **[Connection]** Fixed switching to another server after connection errors.
* **[Error reports]** Added more information about the app and the running mini-app.
* **[Target Window]** Values such as `PathOfExile.exe#2` should no longer be replaced by a window description on their own. Fixed choosing between windows with the `#1` and `#2` suffixes.
* **[Bindings]** Restored Target Window bindings in search triggers and other window-based editors, as well as bindings for overlay position, size and other settings.
* **[Overlays]** Fixed resizing, including resizing with the aspect ratio locked: the overlay follows the edge you drag.
* **[Replica]** Improved region selection and recovery after hiding the overlay.
* **[C# Overlay]** Fixed reopening an overlay after closing its window.
* **[Image Search]** Search frames should no longer remain on screen after unloading an aura.
* **[Behavior Tree]** Fixed node loading hangs when switching between auras, trees and macros, and restarting a tree after unloading it.
* **[Input Simulator]** Added driver installation and removal directly in folder settings, with the current status shown alongside.
* **[Images]** Fixed lost transparency when copying PNGs and video preview errors when changing frames.
* **[Hotkeys]** F8 and F12 can now be assigned in the hotkey editor.
* **[Telegram]** The connection recovers after correcting proxy settings.
* **[Windows]** Fixed content disappearing after minimizing, windows continuing to move after releasing the mouse, confirmations appearing behind the main window, and errors when closing windows and renaming auras.
* **[Export]** After exporting a pack or C# project, Explorer now opens only through the **Open in Explorer** button.
* **[Wiki]** Improved navigation, page lists and image viewing.

**Please report any issues!**
