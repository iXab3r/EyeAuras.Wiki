# Alpha - 1.9.10032 [RU](/ru/changelogs/10032)/[EN](/en/changelogs/10032)

A small patch with fixes for the interface, overlays and behavior tree editor.

## Fixes / improvements

* **[Input Simulator]** Added driver installation and removal directly to folder settings. The current status is now visible next to the button.
* **[Interface]** Fixed confirmation dialogs appearing behind the main window, along with issues when closing windows and renaming auras.
* **[C# Overlay]** Fixed reopening an overlay after its window was closed.
* **[Behavior Tree]** Fixed node loading getting stuck when switching between auras, behavior trees and macros.
* **[Images]** Fixed transparency being lost when copying images. Also fixed video playback and memory cleanup during frame processing.
* **[Hotkeys]** F8 and F12 can now be assigned in the hotkey editor.
* **[Telegram]** The connection now recovers after correcting proxy settings.
