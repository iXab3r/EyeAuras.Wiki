# 1.9.9946 [RU](/ru/changelogs/9946)/[EN](/en/changelogs/9946)

A small patch following [1.9.9942](/en/changelogs/9942). This one mostly contains fixes for overlays and the UI.

## Fixes / improvements

* **[Bindings]** Restored bindings for overlay position, size, offsets, anchors, and other settings.
* **[Overlays]** Fixed jumps and feedback loops while resizing, including aspect-locked resizing.
* **[Replica]** Improved region selection, resizing, and Replica restoration after hiding an overlay.
* **[Image Search]** Search frames should no longer remain on screen after an aura is unloaded.
* **[Codex]** The empty page now fits correctly inside the panel.
