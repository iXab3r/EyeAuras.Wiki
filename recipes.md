# Choose a task to build

Recipes combine several EyeAuras features to solve one concrete task. Choose the result you want, prepare the stated source window or image, then follow the complete setup. Feature guides remain available for individual settings and alternatives.

Start with [Basic recipes](/en/recipes/basic) for tasks that do not require programming. A foreground reminder needs only your own window and entered text; visual checks also need a source that can supply current pixels. A sound recipe needs an available audio output.

| What you want to accomplish | Recipe |
| --- | --- |
| Keep preparation reminders beside your notes, without treating them as recording status | [Foreground recording checklist](/en/recipes/basic/recording-reminder) |
| Distinguish a viewer appearing from its window closing | [Separate open and close cues](/en/recipes/basic/viewer-open-close-cues) |
| Inspect a colored panel only on demand | [Hold-to-inspect color check](/en/recipes/basic/hold-to-inspect) |
| Hear one cue for a real icon appearing in your application | [Ready-icon alert](/en/recipes/basic/ready-icon-alert) |
| Notice a source panel's warning color while working elsewhere | [Off-focus color indicator](/en/recipes/basic/off-focus-color-indicator) |
| Consult your own static diagram or checklist | [Reference image card](/en/recipes/basic/reference-card) |
| Keep one changing area of a window visible | [Live status crop](/en/recipes/basic/live-status-crop) |
| Make a notification gesture eligible in one application | [Application-only notification key](/en/recipes/basic/application-only-shortcut) |

Use the checklist or static card when you already know what you want to display. Choose a visual check when the captured image itself must supply the condition, or Replica when you only need a live copy. The recipes explain which state changes should produce a result and which settings affect that result; choosing a source window does not by itself authorize or send input.
